## 0. 盘点方法与关键结构事实

- 对 internal/ 各包非测试源文件提取顶层声明（type/func/var/const），逐符号做全仓
  非测试引用扫描（含 cmd、desktop、orchestration 等全部消费方）。
- **关键结构事实（决定 agentd 分家走向）**：
  1. 生产代码里 import agentd 的只有 `cmd/*` 与 `internal/orchestration/*`（9 个文件）；
     workspace/client/executor 等对 agentd 只有注释引用，无 import。
  2. `internal/agentd/orchestration_client.go`（k_agentd_orchestration_client，本卡钉死
     留 agentd）文件头载明 B233.13 D1 拍板：`DispatchReq / RecoverReport / RegisterProjectReq
     留 gateway 与 OrchestrationClient 同包；迁出的编排实现 import gateway 取共享 DTO，
     gateway 生产文件不 import orchestration`。`TerminalOutcome` 也在该文件。
  3. 由 1+2：**orchestration→agentd 的 import 方向被钉死**，agentd 生产文件因此永远
     不能 import orchestration（Go 禁循环）。任何「agentd 留驻代码仍按名字/字段引用」
     的符号都搬不进 orchestration——一搬就成环。这是本卡 A/B 分档的硬边界。
