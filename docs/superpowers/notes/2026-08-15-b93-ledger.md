3. （Task 1）`newManagerWithRunningTask` 硬编码 taskID "sweep-task"，与 createRunningTask 显式传 id 的风格略不一致，纯风格项。
4. （Task 2）`ProcFenceConfig` 类型级文档仍以 Disabled/ReserveRatio 为主题，未提两个新字段；每字段已有独立注释，属可选的 doc 完整性增强，非缺陷。

6. （Task 3）README 中英两版的「wait 被哪些事件唤醒」表既没列 `resource_pressure`（同族唤醒事件，既有缺口），新类型不列与现有惯例一致；若将来要补，应同时补两者，不在本 task 范围。
