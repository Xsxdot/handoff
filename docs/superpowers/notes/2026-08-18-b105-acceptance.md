## Step 2：启动期能力播报（审核者实测，通过）

`handoff agentd --config <隔离配置>` 启动日志原文，两行**各出现一次**：

`offset=152` 这行同时是运行期自检的结论：syscall 读出的 cwd 与 `os.Getwd()`

## Step 3：造盲区（审核者实测）

`--new-worktree`（托管形态）派一个 grok 任务，只跑一条命令。

**plan 原配方在 macOS 上跑不通**：它写的是 `nohup setsid sleep 300 &`，
而 macOS 不带 `setsid` 可执行文件，命令静默失败、没造出任何进程
（第一轮 `ps -ax | grep -c "[s]leep 300"` 恒为 0）。改用 python 显式
`os.setsid()` 后成功：

```
nohup python3 -c "import os; os.setsid(); os.execv(\"/bin/sleep\", [\"sleep\", \"300\"])" >/dev/null 2>&1 & echo started2
```

产出的进程确认已脱离进程组与父子链：

```text
$ ps -axo pid,ppid,pgid,command | grep "[s]leep 300"
80020     1 80020 sleep 300
```

（ppid=1、pgid 等于自身 pid，即自成会话——pgid 段与名册段都够不着。）

## Step 4：盲区证明（审核者实测，通过）

`agentd.log` 中 `足迹判定完成` 原文，泄漏进程出现前后各取一行：

```text
（泄漏前）members=3 by_pgid=2 by_roster=2 by_mark=3 mark_only=0 mark_supported=true
（泄漏后）members=4 by_pgid=2 by_roster=2 by_mark=4 mark_only=1 mark_supported=true
```

**判据 `mark_only ≥ 1` 满足**：members 由 3 增至 4，新增的那一个只有标记看得见。
同一时刻 `handoff status` 的活跃任务行也报「4 进程」，与足迹数一致。

## Step 5：回收确认（审核者实测，通过）

```text
$ ps -ax | grep -c "[s]leep 300"     # done 之前
1
$ handoff done 25ae7651-... --note "B105 验收：标记归属与三段回收"
{"ok":true}
$ ps -ax | grep -c "[s]leep 300"     # done 之后
0
```

`agentd.log` 回收段原文：

```text
level=INFO msg=组内无残留，转入点名回收 component=agentd mod=prochost pid=75491
level=INFO msg=标记回收完成 component=agentd mod=prochost pid=75491 candidates=1 killed=1 skipped_older_than_shim=0 skipped_recheck=0
```

这两行合起来是 B105 最承重的证据：**pgid 段与名册段都空手**（「组内无残留」，
且没有出现 `点名回收` 杀掉任何进程的记录），泄漏进程是被**标记段单独**杀掉的。
