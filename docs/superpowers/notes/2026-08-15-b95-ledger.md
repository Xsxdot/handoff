## Task 5 端到端冒烟（临时 datadir + 临时端口，未动 ~/.handoff）

**环境**：`/tmp/b95-smoke`（用完即删）。config.yaml：`datadir: /tmp/b95-smoke/data`，`listen: 127.0.0.1:18977`，`token: b95smoketoken`。仓库：`/tmp/b95-smoke/repo`（origin=git@github.com:Xsxdot/smokeproj.git），另备 repo2（同 origin）、otherrepo（git@github.com:Xsxdot/otherproj.git）。agentd 由 `go build -o /tmp/b95-smoke/agentd .` 产出。

### 1. 登记
```
POST /api/projects {"origin_url":"git@github.com:Xsxdot/smokeproj.git","path":"/tmp/b95-smoke/repo"}
→ 200 {"project_id":"51b79272cf70c7ae","name":"smokeproj","path":"/tmp/b95-smoke/repo","origin_url":"git@github.com:Xsxdot/smokeproj.git","created_at":"...","status":"有效"}
```

### 2. 改名 smokeproj → smokeproj-renamed
```
PATCH /api/projects/smokeproj {"new_name":"smokeproj-renamed"}
→ 200 {"project_id":"51b79272cf70c7ae","name":"smokeproj-renamed","path":"/tmp/b95-smoke/repo",...}
GET /api/projects → [{"project_id":"51b79272cf70c7ae","name":"smokeproj-renamed",...}]  // project_id 未变
```

### 3. 改回原名 smokeproj-renamed → smokeproj，并与初始一致
```
PATCH /api/projects/smokeproj-renamed {"new_name":"smokeproj"}
→ 200 {"project_id":"51b79272cf70c7ae","name":"smokeproj","path":"/tmp/b95-smoke/repo",...}
GET /api/projects → 与第 1 步登记行逐字段一致（project_id/name/path/origin_url/created_at 全同）
```

### 4. 承重不变量：改 path
```
PATCH /api/projects/smokeproj {"path":"/tmp/b95-smoke/repo2"}   // 同 origin 的另一个目录
→ 200 project_id 仍 51b79272cf70c7ae，path 变 /tmp/b95-smoke/repo2
PATCH /api/projects/smokeproj {"path":"/tmp/b95-smoke/otherrepo"}  // 不同 origin
→ 400 {"error":"该目录是另一个项目（origin 不同），请注销后重新添加"}
```

### 5. 边界
```
PATCH /api/projects/smokeproj {} → 400 {"error":"new_name 与 path 不能都为空"}
PATCH /api/projects/no-such-proj {"new_name":"x"} → 404 {"error":"项目 no-such-proj: 记录不存在"}
```

### 6. CLI 往返（一切经 CLI 铁律的冒烟）
```
handoff project edit smokeproj --name smokeproj-cli   → 已更新 smokeproj：新名字 smokeproj-cli
handoff project edit smokeproj-cli --name smokeproj    → 已更新 smokeproj-cli：新名字 smokeproj
handoff project edit smokeproj（两个参数都缺）          → Error: project edit 需要至少一个改动：--name ... 或 --path ...
GET /api/projects → 与初始一致
```

停 agentd（pkill config.yaml 进程），`rm -rf /tmp/b95-smoke`。`~/.handoff` 全程未触碰。
