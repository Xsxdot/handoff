## 3. coordinator_home：降级路径

spec 首选：整搬 + resolver 窄注入。触发降级：新导出面将超过 2 个符号
（供给 `Prepare`、`NormalizeCoordinatorSpec`、`ShellQuote`，再加 resolver 对
`*Server` 的耦合）。实测走降级：

- 纯函数族迁 `internal/orchestration/coordinator_home.go`（供给/规范化/ShellQuote）。
- resolver 留 `internal/agentd/coordinator_sessionref.go`，持 `*Server` 读编制域端口
  与协调者小队。文件头已登记判据。
- 刀3 `best.json`：`k_orchestration_coordinatorHomeSupplier` → `d_orchestration`；
  `k_agentd_coordinatorSessionRefResolver` 保持 `d_gateway`。

e2e 从「真 Prepare→真 runner→假 CLI」单流拆为两段缝契约（orchestration 锁供给内容、
agentd/coordrunner 锁传递）。组合损失是纯函数值拼装，无逻辑可错面（审计 P3-4）。

副作用（审计 P3-2，不挡）：orchestration 测试二进制 `TestMain` 静音；agentd 测试
二进制失去静音，resolver 的 `slog.Default()` 现打 stderr。无断言影响。
