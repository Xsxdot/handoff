## 判断与决定

- 定级沿用 spec L2，单子系统；不触发跨卡审计（L3 专有）。
- task DAG 定为 2 个：Task 1（config+Decide 选值，最薄点亮路径）/ Task 2（payload 观测，两路）。理由：spec 的缝 1（config）与缝 2（Decide）分别落测试；payload 序列化边界是缝外下游，须独立 task + 内部锁声明。
- 观测标签：候选未解析出模型名时，`Attempt.Model` 与 payload `model` 显式记 `"默认"`（`ApproverModelDefaultLabel`），请求 `OneShotReq.Model` 仍为空串（执行者默认语义）。依据 spec 故事 4「未指定时显式记『默认』」。
- 错字校验错误文案 `approver.models 含非候选键 %s（候选: %s）`，先排序再拼，保证 map 迭代无序下错误可复现。
- 弃选：不把「默认」做成可选指针/可空类型区分——模型名今天无判据（B203 OOS），spec 只要人读可观测。
- 未改 `HashPolicyVersion`：链级 model 今天也不入策略哈希，本卡不引入新不变式。
