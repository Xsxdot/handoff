## 四、试错记录

- 首版 `moduleisolation_test.go` 用 `exec.Command("go","list","./...")` + `cmd.Dir=root`；在真实仓根 `cmd.Dir=<仓根>` 实测输出 69 行且不含 mobile，`cmd.Dir=<mobile>` 输出 `.../mobile/bind`——**结论：`cmd.Dir` 有效，`go -C`/`t.Setenv("PWD")` 无效**（后者改不了 Go 的模块定位）。曾一度误用 `filepath.Dir(filepath.Dir(bindDir))` 在扁平探针目录定位失败，已改为与仓根 `TestDesktopModuleStaysOutOfParentBuildGraph` 同款 `runtime.Caller` 定位。
- 探针中独立 module 的替身文件最初命名为 `fakecore.go`（生产名），会被导出面守卫当生产文件扫描；改为 `fakes_test.go`（`_test.go` 不计入导出面扫描）。
- `fakeSessions.SwitchMachine` 首版用 `machine[len(machine)-1:]` 拼 origin，两个机器名尾字符相同导致 origin 相同、断言失败；改为内部递增端口拼 origin。
- 行为断言首版只断言 `cookieA != ""`，变异 4（把 SessionCookie 转发到 SwitchMachine）**不能变红**；把断言收紧为逐字 `cookieA == "sess-devbox"` 后变异 4 变红。**教训：断言钉行为值而非仅非空**。
- 临时探针一律在 `$TMPDIR`（= `/root/.handoff/tmp/1bf5ee2d`，任务范围内）；真实工作树内的临时实现/测试文件跑完即删，`git status --porcelain` 为空。

## 五、S2 依赖的处置（协调者工单 35872f16）

裁决②：S4 自声明消费面（Go 窄接口 duck typing），方法名/签名以 S2 落地为准，S4 只在绑定层适配；S4 真正契约面 = `mobile/bind` 导出面（取 cookie + 切机 + 配对清单 + 关），只用 string/bool，不含 Token/Dial。本 plan 按此实现：`sessionAPI` 为声明性窄接口，生产装配为 `notWiredSessions{}`（fail-closed），并给出 S2 到位后的替换点；行为断言按语义写（切机后旧机 cookie 不可用、一罐只装一机、失败返回错误）。**未向 S2 要内部签名，未发明 S2 冻结物。**
