## 五、变异自验（判据有牙）

```

$ sed -i 's/-androidapi 21/-androidapi 16/g' mobile/build.sh

$ cd mobile && go test ./... -count=1
--- FAIL: TestBuildScriptCarriesAndroidAPI21 (0.00s)
FAIL
FAIL	github.com/Xsxdot/handoff/mobile	0.002s
```
