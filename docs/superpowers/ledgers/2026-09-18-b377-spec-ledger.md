## 4. 真 sed 实测（本机 BSD sed，POSIX getopt 聚簇行为）

```
$ printf 'a\nb\nc\n' > f377
$ sed -ne '1p' f377      → a        （≡ -n -e）
$ sed -ne'1p' f377       → a        （脚本粘连在簇上）
$ sed -nE '1p' f377      → a
$ sed -n -e '1p' f377    → a

$ bash -c "sed -en '1p' f377"      exit=0 out=[a,b,c] err=[sed: 1p: No such file or directory]
$ bash -c "sed -e n '1p' f377"     exit=0 out=[a,b,c] err=[sed: 1p: No such file or directory]
$ bash -c "sed -ne '1p' f377"      exit=0 out=[a]     err=[]
$ bash -c "sed -n -e '1p' f377"    exit=0 out=[a]     err=[]
```

读数：`-ne` 与 `-n -e` 同形；`-en` 与 `-e n` 同形（`e` 的实参是 `n`，`1p` 落成文件名）——故簇里的 `n` 必须在带参字母之前才算旗标。本机无 GNU sed（`command -v gsed` 无输出），GNU 侧假设（`-l` 必带实参）留待实现轮在 linux-01 复核。

## 5. 判断与取舍

- **定级 L1**：改动落在单子系统 `internal/permgate`、不碰契约面；plan 增量为零（spec「实现决定」三条已含全部决定，另写 plan 只会复述）；验收一眼可核（表驱动正反用例 + 真机两条假设复核）。
- **纳入 `--silent`**：GNU 的 `-n`/`--quiet`/`--silent` 是同一个选项的三个名字；卡的口径写的是「含 -n/--quiet」，只补别名不扩语义面（代价：`hasSedQuiet` 一个字符串 + 已知旗标 case 列表一项）。
- **弃选「只放宽纯旗标簇」**：`sed -n -e 'p' f` 已静默而 `sed -ne 'p' f` 不静默，是同形不同判——只修一半等于把噪声留给最常见的写法。
- **边界**：不动 `hasToken` 全局语义（gofmt `-w` 共用点）；不认长选项缩写（`--qui`）。

### 真机 GNU sed 复核（执行机 linux，`sed (GNU sed) 4.9`）

plan 要求复核的两条解析假设（此前 spec 在本机 BSD sed 上测）：

```
$ printf 'a\nb\nc\n' > /tmp/b377f.txt
$ sed -ne '1,2p' /tmp/b377f.txt    → a b        （≡ -n -e）
$ sed -n -e '1,2p' /tmp/b377f.txt  → a b
$ sed -nE '1,2p' /tmp/b377f.txt    → a b
$ sed -ne'1p' /tmp/b377f.txt       → a          （脚本粘连）
$ sed --silent '1,2p' /tmp/b377f.txt  # --silent 存在，但与位置脚本冲突：把 '1,2p' 当文件名
$ sed -en '1,2p' /tmp/b377f.txt    → a b c exit=2  （e 实参是 n，与 -e n 同形）
$ sed -e n '1,2p' /tmp/b377f.txt   → a b c exit=2
$ sed -nf /tmp/b377s.sed /tmp/b377f.txt → a  exit=0 （f 吃下一词元当脚本文件）
```

读法：`-ne` ≡ `-n -e`、`-en` 的 `e` 实参是 `n` 两条假设在 GNU sed 4.9 上成立；
`-nf script` 的 `f` 吃下一词元、`-ne'1p'` 的脚本粘连均确认。`--silent` 是
GNU `-n`/`--quiet` 的别名（`sed --silent '1,20p' f` 与 `--quiet` 同判为静默——
注意 GNU 对 `--silent` 后跟位置脚本的解析与 `--quiet` 一致，都按「脚本是位置参数」
处理）。
