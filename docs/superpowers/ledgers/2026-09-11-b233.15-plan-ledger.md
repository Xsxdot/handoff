## 4. 判断与声明（plan 正文已落）

1. `runshell.go`/`opennonblock_*` 作为 RunCmd 私有闭包随迁（spec §方案表把 RunCmd 列入 workspace.go 行，
   且 git 原语不出包）——plan §4 差异声明 1。
2. `bundle.go` 内容迁入 workspace、agentd 文件删除——plan §4 差异声明 2（Out of Scope 指子系统自身不迁包，
   其 handler 在 server.go，本卡只改调用点；bundle 体不迁就得导出 git 原语）。
3. `reclaim.go` 编排留 agentd，底层巡检/移除助手迁 workspace——plan §4 差异声明 3。
4. `ErrWorkdirGone` 随 RunCmd 迁 workspace；`ErrWorkdirBusy`/`ErrNoProcHeadroom`/`ErrWorkspaceUnavailable` 留 agentd。
5. `workspace_identity_contract_test.go` 随 agentd 副本 `id8`/`taskBranch` 消失而删除（语义由
   `internal/workspace/identity_test.go` 覆盖）——plan §7.2。
