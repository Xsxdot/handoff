事实依据（树上实测）：`session send` 成对 flag=席位 / 无 flag=人（`cmd/session.go:420-441`，成对报错原文 :426「席位身份必须成对出示：--cli 与 --session 需同时给出」）；`ErrNotWriter = "collab: 书写者与房间身份不符"`（`internal/collab/room/errors.go:18`，新模型仍为现行哨兵）；成员集 = 显式成员 ∪ 会话内各卡当前席位、席位权威在 cards.driver_session（`internal/collab/service.go:104`、`internal/collab/room/room.go:101-113`）。

1. **:393-394（占座节，`--cli`/`--session` 消费者清单）**
   - 前：``已有席位的 `card dispatch --step` 和 `kind != user` 的 `room send`；两项必须成对。``
   - 后：``已有席位的 `card dispatch --step` 和协调者出示席位身份的 `session send`；两项必须成对。``
2. **:406-407（占座节，出示席位段）**
   - 前：`` `kind != user` 的 `room send`（`escalation` / `closing` 等）也要出示这场席位；出示\n失败改 `--kind user`，或先 `bind` / `rebind --self`。``
   - 后：``协调者的 `session send`（升级简报、收口摘要等）也要出示这场席位（`--cli` / `--session`\n成对）；出示失败不带 flag 对以人身份发言，或先 `bind` / `rebind --self`。``

3. **:771（排障表，bind/rebind 席位出示行的尾部）**（旧 :745，+26 偏移）
   - 前：`` `--step`/非 user room send 也沿用同一对。``

4. **:775（排障表，书写者报错行）**（旧 :749，+26 偏移）
