## 3. 偏差（记入提交说明）

1. **T6 源码 guard「日志不插值凭据变量」正则盲区修正**（改 T6 文件 `SourceGuardTest.kt`）：
   原正则 `Log\.[a-zA-Z]+\("[^"]*"[^)]*\$(…)\b` 要求方法名后紧跟字符串字面量，而实际日志
   写法是 `Log.<m>(TAG, "...")`，故**恒不命中**。改为
   `Log\.[a-zA-Z]+\([^;\n]*\$\{?([a-zA-Z_][a-zA-Z0-9_]*)\b(?!\s*\.length)` + 凭据变量白名单
   （`value/bundleJSON/setCookieHeader/raw/bundle/token/cookie`）：覆盖 `Log.<m>(TAG, ...)`
   与 `Log.<m>("...")` 两形态；`[^;\n]*` 限单语句；`(?!\s*\.length)` 放行「只记长度」的
   合法写法。
   **变异验证**：临时新增探针 `internal fun mutationProbe(value: String) { Log.i("MutationProbe", "…$value") }`
   → `SourceGuardTest` 8 tests **1 failed（红）**；删除探针 → 复跑 `BUILD SUCCESSFUL`（绿）。
2. **`WebviewActivity` 注释改写**：计划 §11.4 的注释含字面量 `addJavascriptInterface`，
   会被 T6 的 `无JS桥暴露凭据` **词法** guard（扫描含注释的全文）误伤。改为等价中文描述
   「不注入任何原生对象接口」，保留安全语义且不触发 guard（不改 guard 语义）。
