## 2. 产物构建

- `./build.sh ios` 成功：`==> 产物已写入 …/dist/mobile`（26.4 s）。
- `./build.sh android`（脚本原样）**失败**：
  ```
  gomobile: go build -buildmode=c-shared … ./gobind failed: exit status 1
  # gobind/gobind
  link: github.com/wlynxg/anet: invalid reference to net.zoneCache
  ```
  根因：pion/transport v5 的 stdnet 在 Android 上用 `wlynxg/anet` v0.0.5（已是最新）枚举网卡。anet 在 `interface_android.go:164,167` 经 `//go:linkname` 引用 `net.zoneCache`，Go 1.23 起链接器默认拒绝。anet README:123 给出的做法是加 `-checklinkname=0`。这一问题从 B438.1 起就存在（mobilecore→relay→p2p→pion），本卡只是第一次有 gomobile 环境把它暴露出来。
- 带 `-ldflags=-checklinkname=0` 手工 `gomobile bind -target=android -androidapi 21`：成功，`handoff-mobile.aar` 44977710 B。

- 协调者批准方案 A（2026-10-19）：`build.sh` 的 Android 分支加 `-ldflags=-checklinkname=0`（提交 3f71f1a8）。之后在 mac-pro 隔离目录以 `3f71f1a8` **原样跑脚本**：

## 3. Android 模拟器取证

临时 AVD（`ANDROID_AVD_HOME=/tmp/b438.2-…/avd`，`system-images;android-35;google_apis;arm64-v8a`，Android 15）。用户原有的 `Medium_Phone_API_36.0` 的系统镜像不全（缺 system.img），所以没有用它。取证结束后已 `emu kill` 并删除临时 AVD；`~/.android/avd/` 保持原样。

取证程序为一次性代码，不入库：调用 `anet.Interfaces()`，再以 `p2p.Gather` 分两档收集（`stun: []` 与 `config.DefaultP2PSTUN()`），只打印协议/地址/端口/类型，不打候选串与 ufrag。构建方式与 gomobile 一致：cgo + NDK `aarch64-linux-android21-clang` + `-ldflags=-checklinkname=0`。

```
anet.Interfaces: n=3 err=<nil>
gather[host-only]: candidates=1 elapsed=1ms
  udp 10.0.2.16 56579 typ=host
gather[default-stun]: candidates=4 elapsed=3.026s
  udp 10.0.2.16 41637 typ=host
  udp 220.191.116.177 53675 typ=srflx
  udp 220.191.116.177 64321 typ=srflx
  udp 220.191.116.177 63479 typ=srflx
rc=0
```

- 结论：anet 正常枚举，结果非空；host 候选是模拟器网卡 wlan0 的地址 10.0.2.16（`ip -o addr` 对照一致）；缺省 STUN 列表在本网络下可达，收集到 srflx，耗时 3.026 s 即碰到 3 s 收集上限，说明至少一个 STUN 不可达或较慢；全程无 panic。
- 三个 srflx 端口各不相同：模拟器的 slirp NAT 映射随目的端点变化（类对称），跨 NAT 打洞在模拟器网络下预期失败，这正是 S2 的降级路径。
- 对照：同一程序不带 `-checklinkname=0` → `link: github.com/wlynxg/anet: invalid reference to net.zoneCache`（必现）。
- 对照：`CGO_ENABLED=0` 构建时 Go 纯解析器在 Android 上没有 /etc/resolv.conf，STUN 域名解析失败，只剩 host 候选。gomobile 产物走 cgo，不受影响；这只说明取证必须与产物同构建方式。
