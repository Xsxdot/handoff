# 移动入口与设置独立审查

基线 `3e52eb462b7e0213db4c4b8988db91dd3083e84c`，分支 `codex/mobile-entry-settings`。用户批准入口/完整设置稿，指定 gpt-6-luna 本地子 agent 实现。协调者独立读生产消费链、运行测试、实施承重变异并比较实际模拟器截图。

## 裁决

架构轴：当前改动保持 Go 七项绑定与既有协议，壳只消费 opaque bundle、已有 CoreGateway/ConnectCore 和 cookie 进入链；设置 prefs 的数据源与作用范围沿用原实现。标准同源链接为唯一切机入口，DOM 只发布非敏感展示上下文，不形成可调用桥。

目标轴：源码与自动验证已覆盖首次选择、保存后恢复、离线 A 不回落 B、主文档失败不覆盖选择、手动重试重新校验、设置旧能力与返回层级。完整故事验收仍未通过：尚缺配对后选择/设置的实际渲染和交互、扫描/粘贴链路及真机复验。详见根 `design-qa.md` 与执行台账。

## 实现中发现与处置

1. HTTP 404/500 同源 didFinish 提前保存新机器：iOS 用真实主框响应 2xx 与完成条件门控；403 为一般加载失败，401 才走既有过期分类。
2. 冷启动重校验复用重配入口清掉原 A：分离已存 bundle 校验，保持选择；失败断言先红后绿。
3. 单一 WKWebView 切到 B 后失败可能令 A 空白：恢复视图宿主/delegate，按机器名重新进入 A；不假装偏好保存就等于核心已恢复。
4. 导航栈过早收敛与重试只 pop：成功主文档后才留下当前 Console，重试使用当前机；取消导航不误报网络故障。
5. Android reload 丢 DOM 展示上下文：每个验证成功的同源主文档重新发布，不只首次回调。
6. 移动设置重复入口与项目返回层级：显式管理分组，项目可见性返回显示页，关于独立子页，保留全部原设置能力。
7. 保存 A 离线仍普通选择，以及重试读取旧 Core 快照：显示原 A 不可用，只有显式更换打开列表；手动重试重新 Pair 已存 bundle，只允许进入原 A。
8. 重试后更换的 Android 列表快照与 iOS 重试失败返回落点：显式更换重读Core/替换适配器数据，iOS保留原不可用面板等待成功导航收敛。最终源码独立复跑Android54/0、iOS45/45；完整运行验收缺口仍在。

没有将编译错误当作承重测试成功。独立变异把离线 A 分支改成自动恢复 B，原生产路径断言确实 AssertionError；恢复源码后新鲜全量绿。未安装变异产物。

## 已知平台边界

Android 原 minSdk 21 保持。API21–22 无可靠主文档 HTTP 状态回调，不能宣称那里具备 API23+ 的 4xx/5xx 不提交保证；支持范围调整仍等用户裁决。没有为绕过此边界添加 HTTP 客户端或新协议。
