## 1. 问题陈述

B358 spec 实现决定 1 把会话页定为「一等公民页面」（不占 tab 条、无面包屑、无右栏文件树、整块中央区），立卡理由是「家必须随时可回、位置稳定」。sessions-v2 走查后用户改判：家的稳定位置由**左栏 tab 承担**（位置一样稳定，且不独占中央区），会话内容并入工作台 tab 体系，与工作项同列。

## 2. 决定（用户 2026-09-12 走查裁决）

1. **左栏改「会话 | 任务」两 tab 点击切换**：会话 tab = 原「中央区第一栏」的会话列表整体迁入（tab 级未读徽章聚合）；任务 tab = 项目树原样保留。
2. **会话详情作为 tab 参与右侧分屏**：点会话行开成工作台 tabbar 的 tab——可多开（一会话一 tab）、可关（工作项 tab 不设关闭钮，视为常驻入口）、可 `◫` 分屏（工作项左约 46%、会话右）；面包屑与右栏文件树随工作台外壳恢复。
3. **悬浮窗与工作项内嵌 IM 面板直接移除**（B275 残余，用户裁决「直接移除」）：会话入口收敛为左栏会话 tab；群聊↔详情切换原样保留在 tab 内部（⋯ / ←）。
4. 形态基准更新为 `prototypes/b358-session-groups/pages/sessions-v2.html`（对照版 sessions.html 保留）；群聊、详情、投递寻址等内容面与视觉语言逐字同源不变；过程基准 flow.html 不受影响。
5. 分屏形态按本仓词汇实现为 tabbar + `◫` 固定分屏开关（非自由拖拽），走查已接受。
