# B301：跨机 preview raw dial 打 owner loopback；macOS 聚焦不用 xdotool

状态：**已批准**（2026-08-30，用户原话「OK，修吧，你自主推进」）  
定级：**L2**　档位：单子系统修复（补齐 B294 已冻结的 P2 语义；浏览器契约不变）  
卡：B301（发现自 B294 隔离实例 U5）  
日期：2026-08-30  
基线：`cards/B294-implement-6` @ `ec8a9181`  
修订 1（2026-08-30）：live U5 第二根因——`DialPreviewRaw` / relay `RawDialContext` 的 `websocket.NetConn` 不得绑定 Dial 超时 ctx（SOCKS 在 Dial 返回后立刻 `cancel()`，绑上则拨号成功后管道立刻死、HTTP 空回复）。接缝 4 锁此行为。owner 测试 HTTP 与 content 必须不同 host（`::1` 或 `127.0.0.2`；Darwin 常绑不上 `127.0.0.2`）。

## 问题陈述

谁：在协调者桌面点 linux-01（Tailscale direct、无 relay）预览行的人。  
条件：owner `--path` 静态页只绑 `127.0.0.1:0`，或 `--port` 服务只听 loopback。  
通道：本机 SOCKS → `Pool.DialContext` → 应对 **owner 自己** `Dial 127.0.0.1:<port>`。  
现状：`directDialer` 把 `localhost:<port>` 改写成 `机器TailscaleIP:<port>`，协调者直拨，owner 回环够不着。日志：`dial tcp 100.79.27.99:35225: connect: connection refused`。  
第二件：macOS 再点已开行走 unix `xdotool`，500「需要 xdotool」。

## 定级

不动浏览器 DTO/路由语义。补的是 B294 P2 已要求、direct 路径没落地的「owner 拨自己的回环」。新 `GET /ws/preview-raw` 只给协调者 Bearer 用，浏览器不调；与 relay raw 同构，不是新的产品面。L2。

## 方案

1. **direct raw**：`Pool` 对非 relay target 不再把 dest host 改成 `target.Addr` 的主机。改为经该 target 的 `client.Client` 拨 `GET /ws/preview-raw`（Bearer、不走环境代理），用已有 `handoff-preview-raw-v1` 帧把 `network/addr` 交给 owner；owner 在本机 `Dial`（`localhost`/`::1` 归一成 `127.0.0.1`）。非 loopback dest 同样交给 owner 拨（`--via` 的 DNS/出口在 owner；协调者 SOCKS allowlist 仍是第一道闸）。禁止 HTTP CONNECT。禁止浏览器直连 owner。
2. **macOS 聚焦**：`Focus` 从 `!windows` 的 unix 文件拆出。Darwin 用 `osascript` + System Events `unix id`；Linux 仍 `xdotool`。第一次 OpenPreview 仍是 Start，不走 Focus。

## 用户故事

1. linux-01 `preview open --path prototypes/base/index.html`，本机点行，隔离 Chrome 经 SOCKS 取到静态页正文（不只是进程起来）。
2. linux-01 `--port` 只听 127.0.0.1 时同样打得通。
3. 本机 preview 行为不变。
4. macOS 再点已开行：聚焦成功，不报 xdotool。

## 测试接缝

1. `Pool.DialContext`（调用方 `PreviewOpenService.rawDial`）：direct target + dest `localhost:<contentPort>` 必须经过 owner 侧拨号，不能变成 `targetHost:contentPort` 的协调者直拨。owner HTTP 与 content 不同 host，避免同为 `127.0.0.1` 时改写假绿。
2. owner `GET /ws/preview-raw`：Bearer 通过后对 loopback dest 拨通并桥接；无凭据 401。
3. Darwin `previewOSLauncher.Focus`：不调用 xdotool。
4. `Client.DialPreviewRaw`：Dial 超时 ctx 在握手结束后 `cancel()`，返回的 conn 仍能读写（`TestPreviewRawWSSurvivesDialContextCancel`）。relay `RawDialContext` 同契约。

## Out of Scope

- 不加 HTTP CONNECT。
- 不重启现役 linux-01:7777。

- 不在本期做 2h TTL 实耗、Wails 真点击。
