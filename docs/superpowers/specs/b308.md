## 问题陈述

谁：把任务派给 `--executor agy` 跑分的协调者。

登录已通。第一题 `pwd && git status`：handoff 审批链放行后，agy 原生仍 `user denied permission`。agy.log：`required the "command" permission that headless mode cannot prompt for`。

linux-01 任务 `d6740f8c` 的 `settings.json` 只有 B305 名单（有 `command(git)`，无 `command(pwd)`）。同机历史 `run_command`：以 `git`/`ls`/`find` 开头的复合命令未进 denied；**denied 全部以 `pwd &&` 开头**。agy 按命令行**首词**匹配 `command(<target>)`（B305：`command(go)` 能放行 `go env GOVERSION`）。

linux-01 生产 agentd 仍是 `5915c7be+dirty1`，改代码必须停再起。

## 方案

推荐：**在 `nativeCommandAllow` 加上 `command(pwd)` 和 `command(cd)`。** 仍禁止 `command(*)`、`command(uname)`、`always-proceed`、argv `--dangerously-skip-permissions`。PreToolUse deny 继续有效（B305：`command(go)` + deny 能拦住）。

弃选：`command(*)`（B305：hook deny 失效）；改 agy 匹配器（不是我们的二进制）。
