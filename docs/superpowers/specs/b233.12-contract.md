## 2. 冻结清单

每条均可独立判 pass/fail，失败可定位。

1. `executor.ApprovalClient` 四方法签名与本卡基线一致，不增删方法。
2. `approval.Hooks.AutoAllow` 的函数签名保持 `func(taskID string, ev executor.AdapterEvent, verdict permgate.Verdict)`，不新增并列投递钩子字段。
3. `Manager.bindApproval` 组装出的生产 `Hooks.AutoAllow` 实现，执行期间不得调用 `Adapter.RespondPermission`。
4. `Client.Request` 在 `permgate.AutoAllow` 分支不调用 `Store.CreateTicket`，不产生 gate 工单。
5. `Client.consult` 在返回 `ApprovalAllow` 之前不调用 `Store.MarkTicketDelivered`。
6. `Client.Request` 返回 `Decision.Status == ApprovalAllow` 且 `Rule == "approver"` 时，对应工单 `DeliveredAt == nil`。
7. `Client.Request` 与 `Client.consult` 的成功路径都不调用 `Store.MarkTicketDelivered`。
8. `Client.Acknowledge` 仅当 `ack.Stage == AckDelivered` 时调用 `Store.MarkTicketDelivered`。
9. `Client.Acknowledge` 在 `AckFormed` 与 `AckExecuted` 时不写 `delivered_at`。
10. `Adapter.authorizeNativePermission` 对一次 `PermissionID` 调用 `RespondPermission` 恰好一次（含 allow 与 deny 终态；Authorize 失败后的 reject 也计这一次）。
11. OpenCode AutoAllow 终态下 `RespondPermission` 失败不得调用 `NoteDeliveryFailed`，不得追加 `EventTypeDeliveryFailed`。
12. 审批者 allow 之后 `RespondPermission` 失败，`UndeliveredAnswers(taskID)` 含该工单。
13. `FindReusableGrant` 仍要求 `answer` 严格等于 `"allow"` 且 `delivered_at IS NOT NULL`；未送达的 approver allow 不得被命中。
14. `handlePermission` 的 AutoAllow 分支仍对本次权限请求回传一次（非 OpenCode 权威不迁）。
15. 不新增 HTTP 路径、CLI 命令、事件类型字面值、顶层领域。
16. 经生产 `bindApproval` 的 AutoAllow 走进 `authorizeNativePermission` 时，全程 `RespondPermission` 次数为 1；生产钩子次数为 0。

## 5. 拍板记录

1. **钩子只禁投递，不拆光 Hooks。** 难逆转（审批/编排/执行三包都碰）；后人看见 `AutoAllow` 仍在会想「对称 handlePermission 把回传加回去」；否掉的方案是删 adapter 回传或本卡拆除 Judge/Transit/Store。反过来写（钩子再回传）现有替身测试可以仍绿，必须靠冻结第 3/16 条锁住。
2. **免审失败仍不产 `delivery_failed`。** adapter 成为唯一回传后，后人会想「凡 `RespondPermission` 失败都该事件」。否掉的方案是给免审补工单以进 `UndeliveredAnswers`（与 B249 冲突）。无工单路径没有 resume 补投面，事件只能误导。

未命中三重闸门的实现拆分（审计函数与 `handlePermission` 回传如何切）不写入本段。

可执行冻结（哈希/密钥派生/编码金样本）：无命中。

## 6. 移交 plan

以下不占冻结条目、不参与逐条打勾；plan 出稿时吸收。

- 将 `autoAllowPermission` 拆成「只审计」与「审计+回传」两条包内路径：`bindApproval` 只绑前者；`handlePermission` / `respondAutoAllowReplay` 走后者。
- `consult` 删除提前 `MarkTicketDelivered`；日志「已持久化并送达」改为决定已落、尚未送达。
- `authorizeNativePermission` 在 AutoAllow 终态（无工单）失败时跳过 `reportDeliveryFailure`。
- `TestClientConsultAllowPersistsGrant` 改为 `Request` 后 `DeliveredAt == nil`，`AckDelivered` 后非空。
- 测试 1 必须经生产 `bindApproval` AutoAllow，禁止空钩子替身；变异为生产钩子仍 `RespondPermission` 必须红。
