# B233.20 spec：非执行面消费收窄——九个面不再持聚合 *client.Client

## 背景

- 来源：`docs/roadmap.md`「来自 B233.16 spec」非执行能力面的消费点收窄；用户残余清单第 1 类第 3 行。
- B233.16 只收了「一次任务执行闭环」这条缝（8 组合接口 + 9 具名入口 + StepRunner.Clients 收窄）。
  事件镜像、PTY、预览、回收、项目、机器、会话、升级、纯查询命令仍持聚合 `*client.Client`。
- 机制按 B233 定调：**能力接口放提供方**（internal/client，契约冻结物），消费方持接口注入使用；
  聚合 client 编译期断言实现（沿 internal/client/execution.go:52 的 `var _ ExecutionClient = …` 先例）。

## 目标

下列九个面的消费代码不再引用聚合 `*client.Client` 类型（字段/签名/局部变量一律改消费的
能力接口）；`*client.Client` 只出现在提供方与组装点。

## 面清单（消费方 → 收口形态）

1. **任务事件镜像**：internal/ledgermirror——`Machines.For` 返回、`Source`/`DefaultSource`
   签名、`Mirror.clients` 字段；事件流按 roadmap 提示**另立订阅缝**（StreamEventsOnce/ListTasks
   能力接口），不留聚合类型。
2. **PTY**：internal/agentd coordinator PTY 路径中经 `clientForTarget` 拿聚合 client 的消费点。
3. **预览**：agentd 预览转发/镜像路径同类消费点。
4. **回收**：agentd compensate/forward 路径与 cmd reclaim 命令。
5. **项目**：agentd 项目转发路径与 cmd project 命令族。
6. **机器**：machines 相关查询/转发消费点。
7. **会话**：sessions 相关消费点。
8. **升级**：upgrade/自拉换版的远端消费点。
9. **纯查询命令**：cmd 的 tasks/show/diff/attach/frames/footprint/gc 等按命令声明只读能力接口。

提供方/组装点白名单（允许持 `*client.Client`）：internal/client 自身、internal/targetclient
（Pool/New）、cmd 组装根（root.go 的 newTargetClient 族与各命令装配处）、agentd
`clientForTarget`/`forward*`（转发提供方）。

## 验收

1. `go build ./...` 绿。
2. `go test -p 1 ./internal/client/ ./internal/ledgermirror/ ./internal/agentd/ ./cmd/` 绿
   （存量红除外：TestRepoContractGate、TestLegacyNodeEventSequenceUnchanged、
   TestServePermissionHookDenyWithReasonAndStep0、agy permission 族、
   TestCoordinatorCancelTurnUsesSessionID、hostapi wakehome 两条）。
3. 收窄证据：面清单 1–9 涉及的消费代码中 `*client.Client` 引用为 0；grep 原文进报告，
   白名单命中逐个标注身份。
4. 行为不变：CLI stdout/退出码与 HTTP 路径相关测试不改断言通过（沿 B233.16 口径）。
5. 本节点该干什么一律以注入的纪律块为准。

## Out of Scope

- 物理搬迁（B233.19 已做部分 / B233.22 全仓）、非 OpenCode 权威（B233.21）、
  图收口（B233.23/.24）、存量测试红（B233.25）、真机篮子、合 main。
