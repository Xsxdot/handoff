# B281 工作台 IA：左栏项目→任务/目录 + 中央标签组分屏

状态：已批准
定级 **L2**（单子系统 `d_web` / 工作台+壳+左树；不改跨子系统契约。plan 增量非零，不是 L1）
基线：`feat/B281-workbench-ia`
形态对照：`prototypes/b264-tab-groups`（已确认 2026-08-28，确认中；真实页面对照通过后再改为已确认）
并入：B263、B264

## 问题陈述

现在中央工作台以**基准目录**为身份：左栏点目录会换掉整组 tab，右栏钉死文件树。多项目、多机并行时，用户要在「这个目录的现场」和「那个目录的现场」之间整组切换，不能把不同项目的终端 / TUI 放在同一套分屏里看。

谁：桌面/浏览器里的控制台用户。
条件：同时盯若干项目、若干机器上的进行中任务。
变化：左栏按「项目 → 任务/目录」列出进行中任务；目录组里再按机器分组。中央变成与目录脱钩的**标签组**（一套列布局），窗格可以来自不同项目。
观察：点已打开的任务跳到那一格，而不是再开一组；拖机器到分屏开该机主目录终端；文件列表改成可关抽屉。

## 方案

沿确认原型，不另起形态。

### 左栏

- 层级：项目 → 两个同级组「任务」「目录」。目录组内再按**机器**分组。任务和目录是项目下的组，不是机器下的组。
- **任务**：该项目下已打开的终端/文件 tab，加上派发到各机的该项目执行者任务（跨机器平铺在任务组里）。点已打开的 → 跳到它所在标签组的那一格；未打开 → 默认新开一个标签组。可拖到中央分屏。
- **任务行（方案 2，已定）**：固定宽度，标题超长省略号，机器名超长也省略。左侧用头像样式展示**任务类型** icon（终端 / 文件 / TUI 各一套，按类型共用，不按任务 id 随机生成），头像右下角放状态颜色圆点；最右侧展示机器名。不要机头像、不要右侧类型 icon。
- **目录**：按机器分组。机器默认收起，收起时不渲染主目录和工作树，点机器才展开该项目在该机上的主目录和工作树（只显示分支名，不显示路径）。机器行最右侧 hover：开终端 icon、新建工作树 icon（建树沿用现有 NewWorktreeDialog）。拖机器到中央分屏 → 默认打开该机该项目**主目录**的终端 tab。点具体路径 → 打开可关闭的文件抽屉。
- 项目名右侧 hover：工作项、代码图，跳转时带上该项目（B263）。

### 中央

- **不再按目录持有 tab 组。** `useWorkbench` 今日「一个 BaseDir 一份 Workbench」作废；标签组是全局的，不同项目可以出现在同一套分屏里。
- 顶栏是标签组。点左栏未打开任务默认新开一组；分屏挂在组下面；切组即切布局。
- 分屏是**列**：左右贴边加列；一列最多上下两格，一格就占满整列。拖到窗格中间 = 替换该格。不要 2 上 3 下那种宫格。
- 每个窗格承载**一个**内容（终端 / 文件 / TUI），窗格内不再叠一排 tab。
- 当前组「＋分屏」在右侧加一列空窗格。单 tab 组可从顶栏拖进另一组（中间替换，贴边开新列）；组内拖窗格标题贴边同理。
- 列数不设死上限；单列最小宽度沿用现有 `MIN_PANE_PX`。

### 右侧

- 去掉固定文件树。文件列表只以抽屉出现，可关。

## 用户故事

1. 我在本机盯 handoff 的 TUI，同时把 linux-01 上另一张卡的终端拖到右边，两个项目在同一标签组里并排。
2. 我点左栏已经打开的任务，跳到它所在的格子，不会再冒出一组。
3. 我把某个工作树拖到一格的下半边，该格所在列变成上下两格，新格是以该目录为 pwd 的终端。
4. 我 hover 某台机器最右侧的 ＋，按现有流程建工作树；拖这台机器到分屏，开的是该机主目录终端。
5. 我点项目名旁的工作项/代码图，落到对应页且该项目已选中。

## 实现决定

- 改动落在 `d_web`：`ProjectTree`、`useWorkbench`/`tabs.ts`、`Shell`、文件抽屉。不改 agentd 契约；建工作树、开终端、列目录走现有 API。
- 工作台持久化从「按基准目录存 tab 组」改为「存全局标签组 + 列布局」。坏 payload 降级策略沿用现有同步层。
- 整页路由（设置/工作项/代码图）仍盖在工作台上面，不卸载终端（B280 约束保留）。
- 桌面端与浏览器共用这套 Web 壳，不新做原生窗口分屏。

## 测试决定（接缝）

一条缝：`useWorkbench` / `tabs.ts` 的布局模型（调用方：`Shell`、`ProjectTree` 拖放）。

覆盖：已打开则聚焦；未打开则新建标签组；列内最多两格；中间替换、贴边加列；跨项目同组；目录拖放带 cwd；持久化往返。

变异：把模型改回「按 BaseDir 持有」→ 「跨项目同组」转红。

本节点该干什么一律以注入的纪律块为准。

## Out of Scope

- 不改账本、派发、agentd、跨机同步。
- 不重做 TUI 会话协议，不碰 PTY 宿主。
- 不做六宫格/五宫格（已弃选）。
- 不在窗格内恢复「一排文件 tab」。
- 对照原型入库作为形态基准；真实页面仍对照 `prototypes/b264-tab-groups` 验收。
- 不为 home 浮窗终端改白名单（现有 `HOME_BASE` 约束保留）。

## 备注

B263 左栏与 B264 中央是同一张表面，不再拆卡做。弃选：按目录切换整组 tab（现状）；2+3 宫格；任务行方案 1（机头像+右侧类型 icon）与方案 3。
左栏在实现过后再改：项目下任务/目录、目录按机器分组、任务行方案 2。中央分屏仍按已实现的列模型，不推倒重来。
