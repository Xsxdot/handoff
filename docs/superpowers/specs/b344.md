# B344 远端协调者 TUI 转发到执行机

- **卡**：B344
- **级别**：**L2**。plan 不只三行（远端项目路径、建会话、关 tab）。本会话 grok 本地实现。
- **状态**：**已批准**（2026-09-05；用户点名本期做；不做 TUI 自动 bind）
- **基线**：`origin/main` @ `367d5a54`
- **发现自**：B336/B338。不 reopen。

## 问题陈述

`openCoordinatorTUI` 对非本机仍返回「尚未接线」。控制台已有 `POST/DELETE /api/pty/sessions?machine=`。协调者载体在 linux-01 时，应在**那台机器的项目主工作树**打开 CLI，关 tab 时关掉远端会话。不写 HANDOFF_SESSION_*，不自动 `card bind`。

现状：`coordinator_pty.go` 远端直接报错；`pty_api.go` 已支持 `?machine=` 转发；`GET /api/projects` 在目标机列出位置。

## 方案

远端：`clientForTarget` + `MarkForwarded` → `GET /api/projects` 按卡的项目名解析路径 → `POST /api/pty/sessions`（InitCommand 同本机：可选 `HOME=…` + CLI）→ 记下 machine+pty id。关 tab：`DELETE /api/pty/sessions/{id}` 打到那台机器。本机路径（别名 / IsSelfTarget）保持 B338。

弃选：把协调机本地路径当远端 cwd（linux-01 路径不同，会 400）。弃选：TUI 自动 bind。

## 用户故事

1. 协调者载体在 linux-01：coordinate 在那台机器打开终端，cwd 是该机已登记的项目主目录。
2. 卡终态 / 关 tab：远端会话被删，名额归还。
3. 本机 mac-02 / 本机 别名仍走本地 PTY。

## 测试决定

缝：`Server.openCoordinatorTUI` / `closeCoordinatorTab`。

1. 远端：stub 建会话收到 machine=linux-01 与 InitCommand 含 CLI，返回 id；不再含「尚未接线」。
2. 关 tab：stub 删除被调用。
3. 既有本机 target 名 / 本机别名测试仍绿。

## 实现决定

1. `client`：`ListProjects`、`CreatePtySession`、`DeletePtySession`（均建议 `MarkForwarded`）。
2. `openCoordinatorTUI` 远端走上述三步；忽略协调机本地 Workdir。
3. `closeCoordinatorTab` 按 tab.Machine 分流。

## Out of Scope

- **永不做（本期）**：TUI 自动 `card bind`。
- **本期不做**：grok/agy/codex `RunTurn`；空 HOME 当协调者 SessionSpec（仍用 `~`）。
