### 一次差点报成事故的假警报，记下来

第一次列清单我用的是 `git diff --stat 69558368b cards/B156.3-charter-6`，读数是
`docs/roadmap.md | 12 -`——看上去执行者删掉了我刚落的那条重扫判据。**是我的比较基
准错了**：`69558368b` 是我在派发之后才推的提交，不是本轮分支的祖先；对一个非祖先
做 diff，我方的新增会显示成对方的删除。

```
git merge-base --is-ancestor 69558368b cards/B156.3-charter-6   → 不是祖先
git merge-base 69558368b cards/B156.3-charter-6                 → 0d86db172（派发时的 tip）
git diff --stat 0d86db172 cards/B156.3-charter-6                → 3 文件 +490，零删除
```

形态归档：这是今晚同一母题的第六个环节——**比较基准**。前五个是被验对象、注释、
判据、执行判据的工具、送达结果的通道。差别在于这次给出的不是「假绿」而是「假红」，
但成因同构：读数正确，问的问题错了。**判据**：报「对方删了 X」之前先跑一次
`merge-base --is-ancestor`；不是祖先就换成对 merge-base 比。
