### 族一：测试 loopback 服关掉后不得把 Darwin 临时端口押进 TIME_WAIT

推荐（agentd 测试服收口，不是全仓一起改）：

1. **一条测试 HTTP 服务器 helper**，必须放在 **非 `_test.go` 的包**里，让 `package agentd` 与 `package agentd_test` 都能 import。包名归 plan。
2. **本包闭包清单上的每一处** `httptest.NewServer` / `NewUnstartedServer`（现状读数那 21 处）必须经 helper 创建。负例：改完后 `internal/agentd` 内不得再出现未包一层的这两条调用。`httptest.NewRequest` / `NewRecorder` 不占端口，不迁。
3. **RST 两侧**：helper 的 Listener **Accept 之后**对 `*net.TCPConn` `SetLinger(0)`；夹具拨号的**客户端连接关闭前**同样 linger 0。只做 Server 侧挡不住 `http.DefaultClient` / `websocket.Dial` 主动关闭。
4. `ts.Close` 之后 `CloseIdleConnections` 的对象是 `http.DefaultTransport` **以及本测试创建过的所有 `*http.Transport`**（含 `client.New` 那条），不是 helper 私有 Client 自己一份。
5. **Dial 重试作用域**写死为：agentd **测试二进制**里、目标为 loopback httptest 的 `Dial` / `DialContext`。匹配条件仅 `errors.Is(err, syscall.EADDRNOTAVAIL)` 或报文 `can't assign requested address`。次数/间隔有上限，超限错误原文保留这族形状。禁止包 `Client.Do`、禁止改生产 `client.New` 的默认 Dial。`client.New` 在 agentd 测试里连 httptest 时，用测试缝换 Dial（或测试里构造 Client 时注入同一 Dialer）。
6. 生产 `http.Server` / 生产客户端不改 linger，不改重试。

### 族二：`Host.Close` 返回 = shell 已退出且不再写盘

两道屏障缺一不可。只等 `_ptyhost` 进程、而 hostproc 在 reap 返回之前就退出，HOME 写入仍发生在 Close 返回之后。

1. **`Engine.Close` 等现有 `reap`，禁止第二次 `cmd.Wait`。** SIGTERM 整组 → 等现有 `reap` 把 `s.exited` 置位（或已有 done 通道）；`termGrace` 到点仍未退出则 `killPty` 同一进程组，**继续等同一个 reap**。返回时 `reap` 已执行 `s.f.Close()`，PTY 主端已关、shell 已死。废止「DELETE 不该挂 2 秒所以杀进程异步、Close 立刻返回」这条注释——内存列表可以立刻摘，**收摊等待必须发生在 Host.Close 返回前**。`termGrace=2s` 上限保留，不拉长。
2. **`Host.Close` 等的是 `_ptyhost` 已死，不是控制连接的下一帧。** 两条 Wait：
   - **Open 启动的子进程**：必须把 `waitDone` 留在会话上，Close 与失败清理共用，禁止丢掉。
   - **Adopt 登记的会话**：按 `meta.PID`（hostproc 自己的 pid）轮询存活，或等 socket / 会话目录消失，超时与 Open 路径同一预算。Unix 不能对非亲子 `waitpid`。
   发 `CtrlKill` 之后走上面两条之一。EOF / `isTimeout` 不得再当成功。进程不退出则报错返回，仍然 `forget`（避免登记泄漏），错误不能吞。
3. **Host.Close 等待预算**必须覆盖 `termGrace` + hostproc defer 收摊（删 socket / 锁 / 会话目录），从 CtrlKill 被对端处理之后起算，写成 `termGrace + 一个短余量`。禁止从发 kill 起卡死正好 2s——那样 Engine 侧 2s 宽限尚未结束 Host 就会报错，`handleDeletePtySession` 变 500，前端 × 失败再点一次 404。生产 `http.Server` ReadTimeout 30s / WriteTimeout 11min 吃得下，不改生产 HTTP 超时。
4. `shutdownPtySessions` 的 2 秒总预算不动。并发 Close 变真等待之后，最坏会打到这条超时日志——允许，不许为了让关停「看起来更快」把 Close 改回异步。`CloseAll` 的 `ptyCloseBudget=2s` 同样：超时只打日志，不把 Close 改回异步。

弃选：

| 方案 | 理由 |
|---|---|
| 用例里 `time.Sleep` / 重试 RemoveAll | 代理条件换皮，正是 flaky-tests-are-proxy-conditions |
| 只给测试加 `WaitClosed`，生产 Close 保持「EOF=成功」 | 生产 DELETE 与测试 Cleanup 走同一条 Close；两条语义是下一轮漏修 |
| 给 Close 加 `wait=false` | 两条语义，测试走 A、生产走 B，假绿 |
| 把 HOME 从 `t.TempDir()` 改走固定目录躲 cleanup | 不修收摊，只把红换成泄漏 |

红回路（族二，implement 第一件事，未红不许改 Close）：

- 经现网 login shell 路径注入 trap（`Write` 或 `InitCommand`），HOME=`t.TempDir()`，`trap 'echo late > $HOME/late' EXIT`（或等价）。不得另起 `sh -c` 绕过 Engine。
- **今天的红**：Close 返回后立刻断言 **进程仍在，或 `late` 尚未落盘**（二者至少一条。允许竞态里偶发 trap 已写，但不得把 `RemoveAll` 失败当红信号——现网 Close 返回时 Engine.Close 往往还没开始，trap 还没写，立刻 RemoveAll 经常成功）。
- **修完的绿**：`late` **已经**落盘 → `_ptyhost` 与 shell 都不在 → **然后**立刻 `RemoveAll` 成功。禁止用 sleep 拉开窗口。
- linux-01 能跑这条（B202 择位），不依赖 Darwin 端口耗尽。Open 路径与 Adopt 路径各至少一次。

## 实现决定

- 族一只收口 **agentd 测试服**。helper 对以后别人迁是开放的，本卡不替 `internal/executor/*`、`internal/release`、`cmd` 搬家。
- 族一的重试只包测试二进制里连 httptest 的 Dial，不包 `http.Client.Do`，不改生产 `client.New` 默认。
- 族二改的是 `Host.Close` + `Engine.Close` 等现有 reap + hostproc 在 reap 返回前不退出。不改 Attach/Detach（Detach 只关订阅 socket，现网注释保留）。
- Open 路径的 Wait 与 Adopt 路径的 PID/目录等待是同一条 Close 语义的两个实现，不是两个 API。
- 结构化日志：Close 等待收摊打一条（session / pid / 路径=Open或Adopt / 等待耗时 / 是否 SIGKILL）；超时失败打错误。不要只改注释。
- 生产 linger / 生产 HTTP 超时不为本卡改。前端 DELETE 无短超时，不必为 2s 级等待改前端。

## 测试决定（接缝清单）

1. **测试 HTTP helper 的 linger/RST + Dial 重试**（新建符号，必须能被 `agentd` 与 `agentd_test` 同时 import；调用方 = 现状读数闭包清单全部 loopback TCP 测试服）。断言：
   - Accept 侧与客户端侧都 `SetLinger(0)`。Linux 上允许用测试内建连接表/hook 证明这两次调用发生，**不得**把「函数被调用过」当作 Darwin 端口已释放的替代验收。
   - `Dial/DialContext` 对 EADDRNOTAVAIL 重试有上限，超限错误文本含 `can't assign requested address`。`http.DefaultClient`、`websocket.Dial`、测试里的 `client.New` 三条拨号各至少一次打到上限文案。
   - 负例：`internal/agentd` 内不得再出现未包一层的 `httptest.NewServer` / `NewUnstartedServer`。
2. **`Host.Close`（`internal/ptyhost/client.go#Host.Close`）的三条生产调用方**：`Server.handleDeletePtySession`、`shutdownPtySessions`、`CloseAll`（→ `closePtySessionsForStop`）。Open 路径与 Adopt 路径各至少一支。断言：Close 返回后 `_ptyhost` 与 shell 都不在；控制连接超时不再被当成成功。现有 `TestClientCloseRemovesSession` 是 Adopt 路径，要把「Run 返回」收成「shell 已死」，不能只等 1s 墙钟。
3. **`Engine.Close` 等待 reap**（`internal/ptyhost/engine/engine.go#Engine.Close`，调用方 = `hostproc.Run` defer）。断言：返回后 shell 已不在，且 Close **没有**第二次 `cmd.Wait`。可升级现成 `engine.TestCloseRemovesSession`，或让族二红回路下沉到 Engine；不可只改 Host 客户端 Wait。
4. **PTY HOME cleanup**（`pty_ws_test.go` 的 `t.Setenv("HOME", t.TempDir())` 用例是消费方，不是假缝）。红回路见上。至少一支钉在 `Host.Close`（Open 与 Adopt 各一），agentd PtyWS 不需要每条都复制 trap。

假缝禁令：纯函数「算不算 EADDRNOTAVAIL」不占缝。Unix 套接字拨号不占缝（本期不做）。`Host.Write`/`Attach` 里的 `conn.Close()` 不是 `Host.Close`。
