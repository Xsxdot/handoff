## 问题陈述

谁：在工作台终端里跑 TUI 的人。
条件：切到顶栏另一个组 / 进设置再回来。
要变的事实：回来后 TUI 画面正常、滚轮和点击可用。今天花屏、划不动。

`fix/web-tab-unmount-regression` 给组容器补 `min-w-0`，只打「设置页把工作台拉宽再缩回」的 resize 风暴，盖不住顶栏换组。

## 根因

B270 约定后台终端不卸载、不把画布标成看不见。B280 / HomeWindow 进一步禁止 `display:none` / `invisible` / `pointer-events-none`（WKWebView 去掉后命中经常回不来）。

现状（`WorkbenchPage.tsx` `renderGroup`）：后台组是 `absolute -left-[10000px]` + `pointer-events-none`。画布被移出视口，xterm IntersectionObserver 暂停 WebGL；WKWebView 第二次露出来不恢复渲染，也不恢复命中。设置往返叠一条：组是 flex 子项且缺 `min-w-0`，xterm 固有宽把组撑越，ResizeObserver→fit→SIGWINCH 连打。

HomeWindow 已经用「原位 z-index 叠层、不加 pointer-events-none」把浮窗 tab 做对了。工作台组要跟它对齐。

## 方案

后台带终端的组叠在原位：`absolute inset-0`，激活 `z-10`、后台 `z-0`。不加 `pointer-events-none` / 移出视口 / `opacity-0` / `invisible`。组与叠层父容器补 `min-w-0`，切断设置往返的 min-content 撑越。纯文件组切走仍卸载。

不改 PTY、不改 TerminalTab 的 `[I]/[O]` 过滤、不在切回时 fit（B270：第二次 SIGWINCH 会把 TUI 打死）。

## 验收（整张卡）

1. 相关 vitest 绿。
2. 变异：后台组加回 `pointer-events-none` 或 `-left-[10000px]` → 对应用例转红；撤掉组上 `min-w-0` → 对应用例转红。
3. 真机：TUI 里顶栏换组再回来、进设置再回来，画面不花、滚轮和点击可用。

本节点该干什么一律以注入的纪律块为准。
