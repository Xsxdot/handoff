# B280 整页路由卸载工作台终端，TUI 再卡死

定级 **L1**。发现自 B270 验收。B270 修好了工作台内部切 tab；从左栏底部 dock 打开设置 / 工作项 / 流程 / 代码图再回来，同一套「不能输入、不能滚」又出现。

## 症状

工作台里 TUI 正在跑时，点左栏底部「设置」「工作项」等整页入口，再点目录或返回：

1. 滚轮一行一行或完全不能滑
2. 无法输入；只能 Ctrl+C 退出再重进 TUI

看板 / 工单是弹层，不走这条路。

## 根因

B270 的 keep-alive 挂在 `WorkbenchPage` 里。`/cards` `/flows` `/settings` `/codegraph` 把中央换成整页，工作台落在 `path="*"` 上被卸掉。xterm 断 WS，PTY 还在；回来从 `since=0` 重放，OpenTUI/Grok 再吃一遍 1004h / 鼠标追踪，和 B270 同一条病。

`useWorkbench` 的 tab 状态还在，所以看起来像「页面还在」；死的是 xterm 实例。

## 改动

1. **工作台始终挂着**：整页路由盖在中央区上面（不透明底、更高 z-index），不卸载 `WorkbenchPage`。观感仍是「中央换成整页」，左栏还在。不用 `display:none` / `invisible` / `pointer-events-none`（B270：捏尺寸、WKWebView 命中回不来）。
2. **盖住期间终端 `active=false`**：回来再翻成 true，走已有的 focus / 解开 `_isPaused`。不在这条路上 blur / fit / 重连。
3. 右栏文件树、面包屑照旧在整页时不渲染（布局会变一次 SIGWINCH，不断线、不重放）。

不改 PTY 宿主，不重做 B270 的 `[I]/[O]` 过滤器。

## 验收（整张卡）

1. 相关 vitest 绿。
2. 变异：工作台改回只挂在 `path="*"` → 「整页路由期间终端仍是同一节点」转红。
3. 真机：TUI 里从左栏 dock 进设置 / 工作项再回来，能输入、滚轮仍按页。

本节点该干什么一律以注入的纪律块为准。

## Plan

1. `Shell.test.tsx`：开终端 → 点设置/工作项 → `pty-host` 仍是同一 DOM 节点；回来也是。
2. `Shell.tsx`：`WorkbenchPage` 移出 `Routes` 常驻；整页路由绝对定位盖在上面；`active={active && !fullPageRoute}`。
