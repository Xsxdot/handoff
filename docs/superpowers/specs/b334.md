# B334 载体表单变瘦：HOME/凭据选填，machine 必须在 targets

- **卡**：B334
- **级别与档位**：**L1**。plan 增量为零：登记校验与表单默认值已在对话冻死，本文件末尾三步即实现决定。验收一眼可核：Put 拒未知机器、空凭据落 standalone、空 HOME 当主 HOME、新建表单不预填隔离路径。
- **状态**：**已批准**（2026-09-04；对话冻死：HOME/凭据选填、空 HOME=该机主 HOME、空凭据=standalone、machine 必须已是可派发 target，拒在 Put 不在 dispatch；不自动迁 muse 的 HomeDir，不自动建 `~/.handoff/home/<name>`）
- **基线**：`origin/main` @ `f25dea6d`
- **姐妹卡**：B335（runner 禁点名 + origin 交接）、B336（coordinate 开控制台 PTY TUI）。本卡不改派发与 coordinate。

## 问题陈述

设置页新建载体会预填 `~/.handoff/home/<名>`，把隔离 HOME 当成默认形态；凭据又是必填词表，空串直接拒。登记时的 machine 是写死枚举，到 dispatch/detect 才发现不在 `targets`。用户要的日常形态是：载体只要名字、机器、CLI；空 HOME 用该机已登录的主 HOME；机器必须现在就能派到。

## 方案

1. **必填**：name、machine、CLI。HOME、凭据选填。
2. **空凭据**：Put 落 `standalone` 再写库，不把空串存成合法词。
3. **空 HOME**：表示该机主 HOME 与现有登录/skills。不预填、不自动建隔离目录、不迁已有 muse HomeDir。探测：表单空 HOME 不 probe；检测/Wake 把空 path 解成主 HOME。运行命令：空 HOME 只复制 CLI，不拼 `HOME=`。
4. **machine**：Put 时必须是本机别名（`本机` / `local` / 本机 hostname）或当前配置 `targets` 的键。未知机器 `ErrInvalid`（HTTP 400）。表单机器下拉从 `GET /api/machines` 来，外加「本机」。

弃选：dispatch 时才拒未知机器（用户冻死：拒在 Put）。弃选：空 HOME 自动建 `~/.handoff/home/<name>`（那是隔离形态，用户显式填路径才隔离）。弃选：sticky 迁 muse HomeDir（用户自己清）。

## 用户故事

1. 作为登记者：新建载体只填名字/机器/CLI 就能保存；HOME 空着，列表显示「主 HOME」。
2. 作为登记者：选一台不在 targets 里的机器，保存被拒，文案点名机器和 targets。
3. 作为登记者：凭据留空，保存后读回是独立账号。
4. 作为已有 muse 载体的用户：本卡合入后 HomeDir 原样不动。

## 实现决定

- 校验收口在 `PutCarrier`（schedapi 薄层不复制词表）。未知机器检查经组装点注入的 `targets` 键表；未注入时（编制域单测）不拦远程名，避免把账本单测绑到 agentd 配置。
- `WakeHome`/`ProbeHome` 的空 path = 该机 `UserHomeDir`，不得因此 `MkdirAll` 出隔离根。
- 设置页去掉 `defaultHomeDir`/`homeAuto` 预填；凭据下拉缺省仍可显示独立账号（选填=用户不必想，不是必须出现空 option）。

## 测试决定

缝：

1. `scheduling.Service.PutCarrier` ← `handleCarrierPut` / 编制单测：空凭据、未知机器、本机别名、targets 内机器。
2. `scheduling.RunCommand` ← `handleCarrierRunCommand`：空 HOME 只输出 CLI。
3. `hostapi.inspectHome` ← `ProbeHome`/`WakeHome`：空 path 打到主 HOME，不造隔离目录。
4. `SchedulingPage` 登记弹窗 ← 用户：新建 HOME 空、不随名字改写、空 HOME 不 probe、空 HOME 列表「主 HOME」、机器选项来自 `GET /api/machines`。

## L1 plan（同一文件，过 implement 门）

1. `PutCarrier`：空凭据→`standalone`；非本机且不在注入的 known-machines → `ErrInvalid`。`SetupAutomation` 把 `conf().Targets` 键注入。`RunCommand` 空 HOME 只输出 CLI。`IsLocalMachine` 与 agentd 本机判断同源。
2. `inspectHome`：空 path = 主 HOME。设置页：新建不预填 HOME；空 HOME 显示「主 HOME」、跳过 probe；机器下拉 = 「本机」+ `GET /api/machines` 的非空名。
3. 测试：上列四条缝红绿；schedapi 未知机器 400；不写 muse 迁徙。

验收：上述测试绿。本节点该干什么一律以注入的纪律块为准。不自动迁已有 HomeDir。
