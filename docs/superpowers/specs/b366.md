# B366：补员端点与控制台加入会话入口（恢复用户故事 1「原地答」）

- **卡**：B366 ｜ **级别**：**L1 快道**（spec 即 plan，末尾四行即验收）｜ **状态**：**已批准**（依据：B358.6 plan 岔口1 裁决候选 A + B358.7 review F1 升级 + 用户对 B358 流程的连续授权；2026-09-12 协调者定稿，裁决随 B358.6/B358.7 卡 timeline 可查）
- **来源**：B358.4 拍板②核对项 → B358.6 plan 岔口1 证实为实际阻塞 → B358.7 review F1 升级紧迫性。

## 1. 问题陈述

B358.4 拍板①（owner=统一记法）后，控制台发言 actor（`web:<host>`，服务端注入）不在任何会话成员集内（成员=统一记法显式成员 ∪ 卡席位），对会话发言恒 403——spec 用户故事 1「人在群里原地答」不可达。`AddSessionMember` 的 Store/Facade/Client 三层已随 Ticket 0 冻结，缺的只是 gateway 接线与控制台入口。另 B358.6 review I-1：会话 tab 面包屑不显标题（`Breadcrumb.tsx#breadcrumbSegments` 对 `kind:'home'` 吞 tail）。

## 2. 决定

1. **gateway 接线**：`POST /api/sessions/{id}/members`（body: `{identity}`，统一记法前缀校验同 B358.4 拍板①口径）→ `Service`/`LedgerClient.AddSessionMember`；错误映射沿哨兵族（不存在→404 含会话 id、已归档→409、幂等成功）。**纯接线非契约增补**（三层签名已冻结）。
2. **控制台加入会话一键**：403 可行动文案处（会话详情/群聊头部）提供「以当前身份加入会话」——把当前 `web:<host>` actor 坐进成员集（B358.4 偏差#1 已实证该形状：AddSessionMember 幂等零事件副作用），成功后发言链通。
3. **面包屑一行修**：`Breadcrumb.tsx#breadcrumbSegments` 对 `kind:'home'` 基准放行 tail（`return [tail ?? base.label]`），配套测试（会话 tab 面包屑第三段=会话标题；既有 home 场回归）。
4. 不动：wakeconsumer/cmd/internal 其他面；多人时代（登录/多人类成员）仍 OOS。

## 3. Plan（L1 四行）

1. gateway：`internal/agentd/sessionsapi.go` 增 handler + 注册行 + 测试（加员成功/不存在 404/已归档 409/幂等/前缀校验 400/actor 注入反例），路由命名沿用 `/api/sessions` 族。
2. web：403 文案处加入会话一键（rooms.ts 增 `addSessionMember` fetch + 组件按钮 + 测试：403→一键→发言成功链）。
3. `web/src/app/shell/Breadcrumb.tsx` 一行修 + 测试（含既有 home 场回归）。
4. **验收**：`go test ./internal/agentd -run 'TestSession'` 绿且失败集合仍恰 {B362 golden}；web 全量 vitest 绿 + typecheck 0；面包屑新测试绿；`TestRepoContractGate` 清单只多不少；提交限上述文件 + 台账。
