# B347 本机别名与空 HOME 当本地协调者

- **卡**：B347
- **级别**：**L1**。plan 增量为零：两处归一，不改协议。验收一眼可核：`本机` 派发不再 pool 未登记；空 HOME 拉协调者不再报缺 HomeDir。
- **状态**：**已批准**（2026-09-05；编制改小队真机；用户自主清尾巴）
- **基线**：`origin/main` @ `47a57d7b`
- **发现自**：B345 后协调者空 HOME 502；B345 review 载体机写成 `本机` 后 Await 未登记。不 reopen B299/B345。

## 问题陈述

两处「本地」口径不一致。

1. **本机别名**。`scheduling.IsLocalMachine` 认空串 / `local` / `本机` / hostname。`Server.CanonicalTarget` 只认空串和 `config.Targets` 里指向 Listen 的登记名。派发把 target 经 `NormalizeTarget: CanonicalTarget` 写入任务；`resolveStepDiscipline` 里额外的 `isLocalMachine` 折空**没有**用在 Dispatch。真机：载体 machine=`本机` → Await `pool.For("本机")` 报未登记。`mac-02` 在 targets 且指向 Listen，所以改回 `mac-02` 能过；`本机` 不在 targets。

2. **空 HOME**。设置页与 B345：HOME 空 = 该机主 HOME。`WakeHome` / `inspectHome` 已按主 HOME 探测。`normalizeCoordinatorSpec` 空 HomeDir 直接错「协调者 SessionSpec 缺少 HomeDir」。`ResolveSessionRef` 从已上线载体抄 HomeDir，抄到空串后又判「没有已上线载体可恢复 HOME」。真机 workaround 把 HOME 写成 `~`。

图：`codegraph sym CanonicalTarget` → `internal/agentd/server.go#Server.CanonicalTarget`。`normalizeCoordinatorSpec` 图未命中（图覆盖债），源码 `internal/agentd/coordinator_home.go`。

## 方案

`CanonicalTarget` 在 `IsSelfTarget` 之外，对 `scheduling.IsLocalMachine` 也折成空串。未知远端名仍原样交给 pool。`resolveStepDiscipline` 里那段折空可留（幂等），不要再维持第二份「只有探活才折」的口径。

空 HomeDir：`normalizeCoordinatorSpec` 把空当成 `~` 再走既有 `ExpandHomePath`（与登记面 `~` = 主 HOME 同一条展开，不改 `ExpandHomePath` 空串报错——那是 probe path 的契约）。`ResolveSessionRef`：已上线载体的空 HomeDir 是合法主 HOME，补 `~` 再展开；只有小队里没有任何 online 载体才报「没有已上线载体」。

弃选：在 Dispatch 另做一份 `isLocalMachine` 折空、CanonicalTarget 不动（两处口径继续分叉）。弃选：空 HOME 在转发层改写成字面绝对路径（掩盖登记空串语义）。

## 用户故事

1. 作为编制：载体 machine 写成 `本机`，节点派发 Await 走本机 client，不再「target 本机 未在配置中登记」。
2. 作为编制：协调者载体 HOME 留空（或登记面显示主 HOME），`card coordinate` 能唤醒，不再 502 缺 HomeDir。
3. 作为对照：`linux-01` 仍是远端名，CanonicalTarget 不折空。

## 测试决定

缝 1：`Server.CanonicalTarget` ← Dispatch `NormalizeTarget`。
缝 2：`normalizeCoordinatorSpec` ← 协调者 Launch/Resume。
缝 3：`coordinatorSessionRefResolver.ResolveSessionRef` ← attach 补 HOME。

1. `CanonicalTarget("本机")` 与 `CanonicalTarget("local")` 为空串；`CanonicalTarget("linux-01")` 仍是 `linux-01`（配置里该名不指向 Listen）。
2. `normalizeCoordinatorSpec` 空 HomeDir 得到绝对路径，不再返回「缺少 HomeDir」。
3. 已上线载体 HomeDir 空：`ResolveSessionRef` 成功，HomeDir 为绝对主 HOME；小队无 online 载体仍失败。

## L1 plan

1. `CanonicalTarget`：`IsLocalMachine` → `""`。
2. `normalizeCoordinatorSpec`：空 → `~` 再展开。
3. `ResolveSessionRef`：online 空 HOME 合法；测试锁上面三条。

验收：触及包测试绿；变异把 `本机` 折空去掉则缝 1 红；变异把空 HOME 再拒则缝 2 红。本节点该干什么一律以注入的纪律块为准。

## Out of Scope

- **永不做**：把空 HOME 在探测/转发层改写成协调机自己的绝对路径再送给远端。
- **本期不做**：自动把 muse 的隔离 HOME 迁到主 HOME；TUI 自动 `card bind`；删除载体（B348）。
