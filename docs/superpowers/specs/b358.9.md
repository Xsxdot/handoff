# B358.9 会话身份：一名多端（人名收口）+ 协调者跟进

- 父卡：B358（B358.8 走查暴露：控制台无稳定身份，补丁都绕「用户是谁」）
- 级别：**L3（重档）**——跨 agentd 身份解析、collab 写者判定、控制台/CLI 会话面、已读游标重键；档位 breakdown 可纠。
- 状态：**待用户批准**（产品与方案群 2026-09-17 对齐 B 切法后改写；批准后回写本行并交棒 contract）
- 基线：B358.9 分支切出点（contract 节点执行 merge-base 核对并记录 pin）
- 切法：**B**——首卡只做「一名多端 + fail-closed + 不搬家 + 卡进群协调者可 @」；**拉权对称**另开子卡。成员说话权不另做「对称专项」（协调者能说话来自入员，不是本卡政策）。

## 问题陈述

会话房间用传输层临时脸（`cli:<user>@<host>`、`web:<host>`）同时干：证明你是谁、决定能不能说话、决定 @ 叫谁、记录谁干的。一张脸漂了，四件事全错位。本卡定义「人是谁」：权力与 @ 只认固定人名；端只做落款；解析失败拒收；卡进群后协调者必须在场可 @。

承重歧义（已消除）：控制台点发送的人与命令行侧身份，是一个人还是两个人？——一人多名端（见决定）。一端已读是否另一端也已读？——按人合并（见决定）。

## 冻结决定（2026-09-17；含群内改口径）

1. **一名多端**：进门（写权限）、@ 路由、成员名单只认人名；每条发言附带端戳，**只用于落款显示**，不参与权力判定、不参与 @、不参与已读。
2. **已读按人合并**：一端已读＝此人各端都已读。端不拆红点。（作废「分端已读」旧口径）
3. **人的固定名**：用户指定全局名，各机器配同一个。拟定 `user:sycm`（待批准）。配置键拟 `console_user`（待批）。
4. **主 agent 名＝载体/启动身份**：会话里选载体拉起 → 成员名 `agent:<载体>`；外部 CLI 自建会话 → 用启动时身份/载体名，缺则 fail-closed。不是多点一步「声明」，是认「你是谁」的来源。
5. **卡进群 → 协调者跟进（首卡必含）**：拉卡进群路径上，协调者自动写入成员集；可 @、能回话。不另开拉人入口、不另造特权说话旁路。
6. **owner 保持现状**：owner＝创建者＝升级终点；与本卡正交，不扩展拉人/说话特权。
7. **不搬家**：老会话原样不动；经 B366「以当前身份加入会话」点一次加入；已读按新人名自然重建。不写搬家工具。
8. **解析失败 fail-closed**：认不出人名（未配名 / CLI 未带载体）→ 拒绝 + 可行动报错；**禁止旧脸回落**。

## 本卡不做（另开 / 非本卡）

- **拉权对称**（群内任一成员可拉新人、群主零审批）：另开子卡；本卡不落地新拉人政策 op。
- **成员说话权对称**作为独立政策：不做。协调者能说话＝已是成员 + VerifyWriter，不是对称专项。
- 搬家工具：永不做。
- 第二人类（陌生人）模型：永不做。

## 方案（含弃选）

- 采用：人名收口 + 端只落款 + 已读按人 + 拉卡钩子跟进协调者。
- 弃选：一端一名；分端已读；旧脸回落；半新半旧键并行判定；为协调者单开拉人/特权说话旁路；本卡落地「群内任意拉人」。

## 用户故事

- U1 配好全局人名后，控制台发言落款为人名+端，不是 `web:主机`。
- U2 多端同配置：@ 人名，各端都响；一端标已读，各端红点都清。
- U3 故意不配名 / CLI 无载体身份 → 发不出，报错写清缺什么。
- U4 会话内选载体拉起主 agent → 成员名即该载体名，可 @、能说话。
- U5 agent 从外部 CLI 建会话 → 成员名用启动身份；缺则拒收。
- U6 拉卡进群 → 协调者自动在成员里，可 @、能回话；无需另点「拉协调者」。
- U7 老屋经 B366 点一次加入能说话；无迁移动作。

## 契约语义与接缝（L3：定语义，不定签名）

**干净切法（架构师，2026-09-17）**

- 身份解析**只在 agentd 一处**：`transport 事实 → 人名`（缺则拒）。控制台取配置名；CLI/主 agent 取启动载体名；端戳只附发言。
- VerifyWriter：只认成员集里的**人名键**；发话路径先解析再过它；禁止路径里再写 `web:`/`cli:` 分支。
- 已读游标：键＝人名；老键只读冻结，新写入走新人名；禁止半新半旧并行判定。
- 协调者跟进：挂在既有「拉卡进群」路径——卡入席即写入成员集；不走新拉人 op。

测试接缝（符号 + 调用方；签名归 contract）：

1. agentd 身份解析（新建：transport→人名；调用方 sessions 各端点）——一名多端 + fail-closed 收口。
2. collab 写者判定（存量 `VerifyWriter`/`sessionWriters`，调用方 room send）——人名键执法；含协调者入员后能说话。
3. 游标重键（存量符号 contract 钉；调用方 readmodel/cursors）——已读按人。
4. 拉卡进群钩子（存量拉卡路径 + 写成员集；调用方拉卡）——协调者跟进；**不是**新拉人政策 op。

## 实现决定（决策级）

- 用户可见名：`user:sycm`（拟定待批）、`agent:<载体名>`；落款含人名+端名（形态 plan 定）。
- 配置键：拟 `console_user`（待批）；端名来源拟机器名（contract 定）。
- 控制台：配名后发言/ @ / 已读按上列语义；缺名拒收。
- CLI：以启动载体/身份进成员集；本卡**不**新增「拉人」命令。
- 拉卡进群：自动写入协调者成员；可 @。

## Out of Scope

- 拉权对称与新拉人 op：另卡。
- 搬家工具：永不做。
- 登录/鉴权体系改 ticket：不动。
- 端名自定义：不做。
- CLI 人裸发言：用户不用命令行当人说话；须出示席位走既有席位语义（与 agent 启动身份说话无冲突）。
