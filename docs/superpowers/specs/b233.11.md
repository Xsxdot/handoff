## 定级理由

只改 agentd 启动对账「何时允许把共享占用写成 0」。不改占用键、不改 AdmitFrozen/Select、不改 HTTP/CLI。plan 写出来只会复述下面三行；review + 缝测一眼可核 → L1。

## 问题陈述

谁：一台 agentd 进程启动时做调度占用对账。

条件：`sched_running` 在共享账本上，跨机可见。任务表在本机 Store。B233.10 把「本机任务表没有非终态 owner」的键一律清零。本机没有那条任务，不等于集群里没有占用者（另一台机器上的执行、没有 Task 的 `LaunchAdmit` 会话）。

通道：现有启动路径 `Server.RecoverOnStartup`。不新造 HTTP/CLI。

要变的事实：**启动对账不得把共享占用清零，只因为本机任务表里看不到 owner。** 本机非终态任务仍占用的键继续保留。本机任务已终态，也不能当借口清零——同一载体计数可能含他机。谁能观察到：共享键上他机/协调者的占用，在本机重启后仍在。

## 现状事实（B233.10 HEAD `6b923c79`）

| 事实 | 出处 |
|---|---|
| 对账读本机 `ListTasks` 当 owner | `internal/agentd/watchdog.go#reconcileSchedRunning` |
| 不在该集合且 count>0 的键被写成 0 | 同上，对 `repo.List("sched_running")` 全量循环 |
| 占用 Registry 跨机可见 | B233.10 spec；本环境 Postgres |
| 生产入口 | `internal/agentd/server.go#Server.RecoverOnStartup` ← `cmd/agentd.go` |
| 无本机任务即清零被测试锁住 | `TestB23310RecoverClearsOrphanCarrierAndMemberIndependently` |
| 本机终态任务的键也被清零 | `TestB23310RecoverKeepsWaitingReviewAndRunningOwners` 后半 |

## 方案

启动对账对共享占用只许「看见本机非终态 owner → 保留」。**禁止**因「本机没有 owner」或「本机对应任务已终态」而 `Put` count=0。

本机终态漏释放、AdmitFrozen 后 CreateTask 崩溃的无主窗口，本期不靠启动对账猜。猜就是跨机误伤。

**弃选**

- **继续无主即清。** 与用户原话相反。否。
- **占用记录写 task/machine owner 再按 owner 清。** 能顺带收崩溃窗口，但改共享占用体，超出本卡「别跨机清别人」。后续卡。否。
- **只清本机终态任务对应键。** 计数是共享的，终态本机任务不能证明他机没占同一键。否。

## 用户故事

1. 共享账本上载体 A 占用=1，本机任务表空。本机 `RecoverOnStartup` 后 A 仍是 1。
2. 本机有 running 任务占 A，他机占 B。本机重启后 A、B 都还在。
3. 本机有 completed 任务曾占 C，共享 C 仍为 1。本机重启后 C 仍是 1。
4. pending/running/waiting_review 本机 owner 仍不被改写（B233.10 已锁，保持）。

## 实现决定

- 不改命令、HTTP、占用键名、Select/AdmitFrozen。
- 启动对账失败（解码错误等）仍阻断后续 executor 恢复。
- 可以打日志说「看见无本机 owner 的键」，但日志不是清零授权。

L1 plan（同一份文件过 implement 门）：

1. 改启动对账：共享 `sched_running` 不得因本机无非终态 owner 而写成 0。
2. 测试：无本机任务的占用保持；本机终态不得清共享键；本机非终态 owner 仍保留。变异：再写回清零，上述测试必须红。
3. 不要重写 Select/AdmitFrozen，不要合 main，不要动父卡 B233.10 的 finish 裁决。

## 测试决定

最高可测缝：`internal/agentd/server.go#Server.RecoverOnStartup`（调用方 `cmd/agentd.go` 启动路径）。

1. **无本机任务不得清**（缝上）：共享键 count=1、本机无任务，Recover 后 count 仍 1。
2. **他机键与本机 owner 并存**：本机 running 占 A，共享另有 B 无本机任务；Recover 后 A、B 都保持。
3. **本机终态不是清零授权**：本机 completed 占 C，共享 C=1，Recover 后 C 仍 1。

假缝：`reconcileSchedRunning` 未导出，不占接缝名额；测试必须打 `RecoverOnStartup`。
