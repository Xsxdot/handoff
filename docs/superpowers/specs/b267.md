# B267 终端查询回包、花屏、滚轮

定级 **L1**。实现已在本会话落地，本页是回填的 spec+plan，供验收对账。

## 症状

桌面端工作台 PTY：① 提示符出现 `2RR0;276;0c` / `rgb:0b0b/…`；② TUI 花屏，拖窗口才好；③ Grok 滚轮按消息翻、长输出看不到，Codex/OpenCode 滚一点就卡住。

## 根因

xterm.js 把 DA / OSC 颜色 / CPR 答包经 `onData` 写回 PTY；切 tab 重放环形缓冲会再答一遍。工作台面板 `overflow-auto` 吃掉凑不满一行的滚轮。三次伪造滚轮（方向键 / 自造 SGR / 方向键+吞输入带）都跟原生终端分道：OpenCode 把方向键当输入历史，假 SGR 坐标把整屏划走。

## 改动

- `web/src/app/workbench/terminalHostResponse.ts`：识别设备回包；不处理鼠标报告（用户动作，必须上送）。
- `terminalWheel.ts`：把滚轮像素折成多格同坐标 SGR（xterm 每次 DOM 事件只发一格）。
- `TerminalTab.tsx`：回包不上送；fit 后 refresh；WebGL 后再量一次。鼠标追踪下按指针格子连发 SGR，不改方向键、不造假坐标。
- `WorkbenchPage.tsx`：面板 `overflow-hidden`。

## 验收（整张卡）

1. 相关 vitest 绿。
2. 把 `isTerminalHostResponse` 改成恒 false，对应测试转红；还原回绿。
3. 真机：提示符不再出现 DA/OSC 乱码；TUI 不花；Grok/Codex/OpenCode 滚轮跟系统终端一样——指针在对话区滚对话，在输入框才动输入；触控板一甩能翻页，不必滑好多轮。

本节点该干什么一律以注入的纪律块为准。

3. 验收：复跑 → 变异 → 真机。
