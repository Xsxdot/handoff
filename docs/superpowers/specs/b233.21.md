# B233.21 spec：非 OpenCode 权限/提问权威收口——决策核心迁 approval，Manager 只留账本机制

## 背景

- 来源：`docs/roadmap.md`「来自 B233.10 spec」审批拥有审批事实段；4485a4e7 审查 F1；用户残余清单第 1 类第 4 行。
- B233.12 之后 OpenCode 的审批权威在 internal/approval（Hooks 不投递、送达只在原生回传成功后）；
  **非 OpenCode（claude/grok/codex/agy）的权限/提问权威仍在 Manager**：
  `handlePermission`（internal/orchestration/manager.go:2018）内联了判据 judge（:2122 permgate）、
  AutoAllow（:2251）、重放幂等（:2602/:2656）、复用（:2731）、审批者 consult 分流（:2322）、
  escalate（:2067）；`handleQuestion`（:2923）同在 Manager。
- B233.10 定调：**审批拥有审批事实——政策、决策、升级、送达确认有唯一归属；harness 只做
  原生协议转换**。「非 OpenCode 权威仍待迁」即本卡。

## 目标

非 OpenCode 权限请求的**决策事实**（判据 verdict、AutoAllow 决定、决策复用、重放幂等）由
internal/approval 权威所有；Manager.handlePermission 收缩为「收 adapter 事件 → 调权威 →
按权威结果落账本事实（工单/状态/事件/waiter/Publish）→ 原生回传」。提问路径的工单身份与
复用语义同样经权威 API；行为逐字节不变。

## 范围

1. **权限决策权威**：judge/reuse/autoallow/重放幂等的实现体迁 internal/approval（新权威
   API，非 OpenCode 用；OpenCode 既有 Request/consult/escalate 面不动）；Manager 持权威调用。
   迁移后 Manager 不再含 permgate 判定与 AutoAllow 决策实现体（grep 可证）。
2. **审批者 consult/escalate 分流**：consultApprover/escalatePermission 的**账本机制**
   （工单、状态迁移、waiter、Publish）留在 Manager（这些是编排域事实）；分流**决策**
   （该不该 consult、inflight 标记语义）随权威走。实施中若双路共用导致行为漂移风险过高，
   允许降级：本卡只迁 judge+reuse+autoallow+重放幂等（决策权威），consult/escalate 留
   Manager 并在本卡 note 记残余——不得出现两处权威并存的中间态。
3. **提问权威**：handleQuestion 的账本机制不动；工单身份/应答路由的权威入口落 approval
   包（ask 无政策判断，成本应很小）；若实施证实与权限面共享内核成本过高，允许维持现状
   并在 note 记「提问面维持 Manager，权威化待后续卡」——二选一，如实落账。
4. **Claude 注入快照**：核实「Claude 注入只服务快照（B233.8）」的现状并记录；本卡不改
   claude adapter 的注入行为。
5. 冻结契约不破：ticket id 命名空间化（taskID:permID）、顺序契约（先状态→工单→waiter→
   Publish，P1-2）、AutoAllow 不建工单不发事件不改状态、manager.go 注释里的冻结标注
   （如 #14）全部保持。

2. `go test -p 1 ./internal/approval/ ./internal/orchestration/ ./internal/executor/... ./internal/agentd/ ./cmd/`
   绿（存量红除外：TestRepoContractGate、TestLegacyNodeEventSequenceUnchanged、

   存量 flake）。
3. 缝级证据：新增/改写测试证明非 OpenCode 权限三出口（AutoAllow / consult / escalate）
   的**决策**出自 approval 权威；重放幂等与复用走权威。测试名与断言进报告。
4. grep 证据：Manager 内 permgate 判定/AutoAllow 决策实现体迁出（grep `judgePermission\|autoAllowPermission\|reuseDecision` 的落点对照）。
