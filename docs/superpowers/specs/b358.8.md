# B358.8 走查反馈修复批：会话页 8 项交互缺陷

- 父卡：B358（acceptance 真机走查轮产出，2026-09-13 截图走查，反馈原文见 B358 卡 note seq 13796）
- 定级：L2（8 条集中在 web 会话前端，跨多组件交互改造，单执行机一波修完）
- 基线：linux-01 上 B358 实现分支（integrate pass commit `91f6cbeb` 或其后继分支头），修复分支从它切；不基于本地 main
- 范围红线：只动 web 会话前端与其只读数据供给；既有后端会话语义（发言、寻址、未读、拉卡 API、归档）一律不改。#7 预期前端默认填当前用户即可，若确需后端默认值再在 plan 轮说明理由

## 背景

B358 acceptance 真机走查（隔离实例 7778，用户 2026-09-13 19:58 截图）发现 8 项交互缺陷/改进项。全部是会话页（sessions 一等公民页面 + tab 组工作区）范围。

## 修复项（目标形态与验收判据）

### 1. 左侧会话列表拖拽分屏失效

- 现状：左侧会话列表条目拖不动，无法拖出形成分屏。
- 目标：从左侧列表拖动会话条目到右侧 tab 工作区，可落成新 tab 组（分屏）；拖到已有 tab 组内则作为该组新 tab 打开。拖拽过程中要有可放置的视觉提示（drop 区高亮或插入指示）。
- 验收：真机拖拽左侧会话条目 → 形成新分屏组或落入既有组；与 workbench 既有 tab 拖拽行为一致（若 workbench 已有拖拽基建则复用其机制）。

### 2. 回复快捷入口 + @ 输入联想

- 现状：回复与 @ 只能手敲，无快捷入口、无联想。
- 目标：
  - 回复：气泡 hover 时右侧出现「回复」快捷按钮（或右键菜单含「回复」）；点击后输入框进入回复态，显示被引用消息的引用条（可取消）；发送后消息带 reply_to 引用（reply_to 发送半边若仍在 B365 在途，本卡至少完成前端回复态与引用条，发送端语义与 B365 对齐不重复建设）。
  - @：输入框键入 `@` 后弹出候选面板，候选 = 会话成员（席位/人）与可提及对象；候选随后续输入实时筛选；点选或回车插入 mention。候选数据用既有会话详情接口的成员列表，不新建后端端点。
- 验收：真机 hover 气泡出回复按钮、点击进回复态可取消；键入 @ 出候选、输入筛选生效、点选插入。

### 3. 会话页头部精简 + 拉卡入口移位 + 「更多」改抽屉

- 现状：头部行数太多——tab 条下有重复标题行 ×2 + 群主行 + 卡列表行；「拉卡进群」按钮在头部；右侧「…」更多点击后覆盖式弹层。
- 目标：
  - 删掉群主行（群主信息收进抽屉里的成员区）。
  - 标题只保留一行（tab 条已有标题，页内头部至多一行标题，不再重复）。
  - 头部不再展示卡列表（卡列表收进「更多」抽屉）。
  - 「拉卡进群」入口移到输入框左下角，作为输入框工具按钮。
  - 「…」更多按钮点击改为**右侧抽屉（drawer）**打开，与会话框并存（覆盖式弹层改为侧滑抽屉，会话流仍可见可滚动）；抽屉内容含成员列表（含群主标识）、会话卡列表、归档入口等既有头部功能。
- 验收：真机头部 ≤ 一行标题 + 操作钮；输入框左下角有拉卡按钮；点「…」右侧滑出抽屉、会话流仍可见。

### 4. 删右上角「分屏」按钮

- 现状：右上角「分屏」按钮来历不明（spec 未定义），点击无反应。
- 目标：直接移除该按钮。分屏能力由 #1 的拖拽承载。
- 验收：右上角不再有「分屏」按钮。

### 5. 删 tab 组标题右侧「+」号

- 现状：tab 组标题右侧有「+」按钮，用途不明。
- 目标：移除（若它是「新建会话」入口，则新建会话入口保留在左栏既有「+ 新建会话」按钮，不在此重复）。
- 验收：tab 组标题右侧无「+」。

### 6. 会话列表按项目筛选

- 现状：会话 tab 下方「按项目筛选」未做（spec 有此要求，实现缺口）。
- 目标：左栏会话列表上方提供项目筛选（下拉或既有筛选控件样式），选中项目后左侧会话列表只显示该项目（含其卡锚定）的会话；「全部」为缺省。
- 验收：真机选择某项目 → 列表过滤生效；切回全部恢复。

### 7. 新建会话默认群主为当前用户

- 现状：新建会话表单要求手输群主身份。
- 目标：群主缺省 = 当前登录用户，表单不再强制手输；保留改选能力（可下拉选其他成员），但打开表单即可直接提交。
- 验收：真机打开新建会话 → 不输任何身份字段可直接创建成功，创建者即群主。

### 8. 拉卡进群改卡选择器

- 现状：拉卡进群要求手输卡号。
- 目标：点击拉卡按钮弹出卡选择器：列出可选卡（复用既有卡列表数据），支持按标题/卡号搜索过滤，支持多选；确认后批量拉入会话。
- 验收：真机拉卡 → 从列表搜索并勾选卡 → 确认入群成功，无需手输卡号。
