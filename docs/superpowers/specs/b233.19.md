# B233.19 spec：agentd 前台包收尾——项目登记、事件镜像、预览仓主迁出

## 背景

- 来源：`docs/roadmap.md`「来自 B233.15 spec」工作区域剩余文件的迁包；用户残余清单第 1 类第 2 行。
- B233.15 只搬走 git/工作区实现。四摊实况核对（基点 59dfb16c5）：
  - **回收编排**：已随 B233.13 在 `internal/orchestration/reclaim.go`（Manager.Reclaim/ReclaimList），
    agentd 只剩 handleReclaim/handleReclaimList HTTP 面——合规，本卡只验证、不再搬。
  - **git bundle**：已在 `internal/workspace/bundle.go`（B233.15 实现轮）——合规，只验证。
  - **项目登记族**：`projectadmin.go`(444)/`projectfanout.go`(111)/`projectjoin.go`(59)/
    `projectresolve.go`(99)/`projecttree.go`(103) 仍在 agentd。best.json：`k_agentd_projectIndex → d_workspace`。
  - **事件镜像**：`mirror.go`(431) 仍在 agentd。best.json：`k_agentd_Mirror → d_workspace`。
  - **预览仓主**：`preview_owner.go`(554) 仍在 agentd；preview 容器族在 best.json 未登记
    （留 B233.23 重扫时补登记）。

## 目标

internal/agentd 不再承载这三摊的**非 HTTP 实现体**；域逻辑分别落 best.json 指定域的包；
agentd（gateway 域）保留 HTTP/WS 消费面，经**消费方本地窄接口 + cmd 注入**取回实现——
internal/workspace 不得新增对 store/targetclient/agentd 的包级 import（零新增跨域边）。

## 范围

1. **零新边直迁**：projectfanout/projectjoin/projectresolve（只 import proto）整文件迁
   internal/workspace，测试随迁。
2. **projectadmin/projecttree**：HTTP handler 留 agentd；登记/索引逻辑迁 workspace；
   store 触点收成 workspace 本地窄接口，agentd（或 cmd）侧写 store 适配器，cmd 注入。
3. **mirror.go**：Mirror 发现/订阅/快照循环迁 workspace；targetclient 与 store 触点收成本地
   窄接口，适配器留 gateway 侧，cmd 注入；WS 推送面留 agentd。
4. **preview_owner.go**：owner-truth 校验/持久化/发布迁 workspace（落位理由：已 import
   workspace，落进去减边；preview 容器 best.json 未登记，B233.23 补登记）；
   PreviewProxy/PreviewStatic/PreviewLauncher 等 HTTP/OS 面留 agentd。若实现证实不可行
   （循环依赖等），**降级方案**：整文件留 agentd，本卡 note 记录「待 best.json 登记后再搬」，
   不得半搬。
5. 测试随迁；行为不变。

## 验收

1. `go build ./...` 绿。
2. `go test -p 1 ./internal/agentd/ ./internal/workspace/ ./cmd/` 绿（存量红除外，同 B233.18 清单）。
3. 盘上证据：internal/agentd/ 不再有 projectfanout.go/projectjoin.go/projectresolve.go/
   mirror.go/preview_owner.go；internal/workspace/ 收纳对应实现与测试。
4. 依赖方向证据：internal/workspace 非测试文件不 import internal/store、internal/targetclient、
   internal/agentd（grep 原文进报告）。
5. 行为不变：agentd 相关 HTTP/WS 测试不改断言通过。
6. 本节点该干什么一律以注入的纪律块为准。

## Out of Scope

- client.Client 聚合收窄的消费面（B233.20）、非 OpenCode 权威（B233.21）、
  internal/ 全仓重排与 preview 容器 best.json 登记（B233.22/.23）、合 main、真机。
