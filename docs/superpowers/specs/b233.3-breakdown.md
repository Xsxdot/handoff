## 4. 缺陷族对抗审查

项目清单：`docs/superpowers/specs/2026-08-21-handoff-instantiation-checklist.md` §3（五族 + 序列化边界 + 枚举白名单 + webview 候选）。顶部**没有**「基线版本：charter@\<commit\>」——对不上基线标注，本拆解按项目清单加严，并并入基线追加「承重安全属性」。清单债不在本卡改实例化协议。

### 4.1 通用五族

**生命周期 / 状态机中断**

- 选路：`New` 不发网络；relay 隧道惰性建立。进程在首次请求前退出 → 无隧道可收。池持有的隧道由 `Pool.Close` / 配置变更 `cleanup` 收；调用方不得关 `For` 返回的隧道（冻结 8，T1）。
- wait：cursor 在协调者本机文件。agentd 重启不删 cursor；重连凭 `from_seq` 补拉（T4）。cursor 写失败不吞已返回事件。
- 挂卡：forward 成功、挂卡中途崩溃 → P4-(a) 可能树已建、卡未挂。恢复策略不是本卡新资源类型；T5 保持「单张失败不删树」。不得只靠内存。
- 隧道：`Dialer.Close` 置 `closed`，禁止再惰性重连当成功（T3）。孤儿 yamux session 由 Close 收。
- **无新孤儿类型，因为**不新增进程/工单表/临时目录种类。upgrade 旁路收口（P2）不改变换版生命周期。

**静默失败 / 误导报错**

- Dispatch 失败不得返回成功 Task（既有 client 解码路径，T2/T6 保持）。
- 无端点必须 `ErrNoEndpoint` 且点名 target，不得退化成 `client.New("")`（历史 bug，工厂已挡）。
- Warm 成功当成 agentd 可达 = 误导；T1 反面断言（冻结 9）。
- 隧道断开报成「机器未登记 / 不可达」= 误导处置；T3。
- ctx 取消报成 `ErrUnreachable` 会让降级分支在 Ctrl-C 后继续；已有测试，T3 保持。
- 目标建树失败本端报挂卡成功 = 禁止（既有 T5 错误路径）。
- 转发剥掉 `card_ids` 后若本端也不挂，Web 仍显示成功且 `CardResults` 空/省略 → 界面上看不出异常（forward.go 注释原文）。P4-(c) 会制造这个窗口；P4-(a) 避免。
- `HTTPClient` 新路径乱拼失败时，错误不一定走 `ErrUnreachable` 哨兵；用白名单禁止新路径（T2）。

**跨平台假设**

- 本卡不新引入路径分隔、进程组或 webview 假设。cursor 路径沿用既有 `cursordir.go`。
- relay / 直连是网络与隧道，Windows 上 `localhost` 占位、yamux、websocket Dial **未验证，需真机**（§5）。握手字节本卡不改，不引入新平台假设。
- **无其它新平台假设，因为**选路输入是 `config.Target` 字符串字段，测试锁的是 `BaseURL` 字面值不是 inode。

**假红 / 假绿测试**

- Ticket 0 金样本锁编码，不是「跨机故事已完成」。不得把空壳存在当故事 1 绿。
- `TestForwardWorktreeStripsCardIDsAndAttachesLocally` 今日正向锁「forward 路径挂卡」。T5 必须改锁「剥 card_ids + 应用挂卡 + forward 源码不写账本」，否则新实现假红，或留下旧正向造成假绿。
- `who-calls HTTPClient` 空 ≠ 无调用方（`unscannedEntries=5`）。白名单测试必须走读源码，不能信图。
- Warm / New 构造测试不得冒充连通性。
- 夹具可以编码「策略过滤但 WS 层已丢帧」的世界——`all=true` 必须是反面断言（T4）。
- 测试锁的是调用方依赖的行为（BaseURL 分叉、禁标准头、forward 不写卡、WaitEvent cursor），不是 `WaitDeliveryPolicy` 内部 case 顺序。
- 全包测试若遇沙箱 `Operation not permitted`：记原文，不归因；T6 要求无沙箱环境复跑。

**门禁绕过**

- 具名 relay 绕过工厂走 `client.New` 会得到错误 BaseURL / 无隧道，这是通道分裂不是权限门，但会让「看起来在说话其实没走 E2E」。P2-(a) 收 upgrade；其它生产具名入口已走工厂。
- `HTTPClient` 是绕过能力面的写路径。门覆盖：源码白名单测试锁全部非测试 `.go`，不是抽查。检查与动作同一提交（测试即门）。
- 网络认证（Bearer / relay token 熵）≠ 任务操作授权。本卡不新开审批 HTTP，不把 token 当审批。
