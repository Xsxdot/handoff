## 已定的产品规则（实现必须遵守）

1. **状态固定六类**，一色一形：运行中（绿·实心点）、空闲（灰·空心圈）、需要你（琥珀·气泡）、等待中（蓝·时钟）、异常（红·三角）、未知（浅灰·虚线圈）。chip 主文字 = 状态名 + 时长；原因等自由短语只进 hover 提示与详情。
2. **没有常驻「我」**。有待你处理的工单时，状态条最前出现「需要你处理 N」，点击打开待处理抽屉，直达对应工单（可在抽屉内批准/拒绝/回答，答完跳下一张）。
3. **排序**：需要你 > 异常 > 等待中 > 运行中 > 空闲 > 未知，同类按时长长者在前；只有需要你/异常带底色。
4. **一切可点**：横幅打开它所说角色的详情；异常详情给下一步按钮（重新唤醒协调者 / 查看卡 / 查看日志）。
5. **溢出逐级收紧**：异常永不进 +N；空间不够先折叠「需要你」角色 chip（已由「需要你处理」按钮代表，按钮 hover 列出是谁）→ 安静角色缩成头像（头像带卡号/任务号末两位）→ 去时长 → 最不紧急的收进「+N」（含需要你/异常时 +N 带色点）。≤650px 两行布局。
6. **命名固定**「角色类型 + 卡号」：协调者 · E38、驻场者、执行者 · T-774；头像字 协/驻/执。
7. **详情三段**：结论 → 原因 → 你可以做什么；之后「最近动态」（默认展开，最近 3–5 条，倒序，一行一句；失败红、等你琥珀、其余灰；超出显示灰色不可点「更早的记录…」）；最后默认折叠的「技术细节」（内部编号、原始证据）。
8. **最近动态只用现有数据源**：唤醒轮次开始/结束/失败、房间发言摘要、工单创建/答复、任务派发/回合结束/归档。不展示每轮完整收到内容与输出——那是拆出的卡 B471。
9. 无协调者时不出 chip，用横幅说明；协调者无任何记录显示「未知」；单纯等待（如 26 分钟没人接）是「等待中」不是「异常」。
10. 页面其余部分（项目树、标签页、消息区、输入框、额度条）不变。
