# B342 非 opencode 载体检测：找得到命令就算上线

- **卡**：B342
- **级别**：**L1**。plan 增量为零：未实装 CLI 的 WakeHome 不发检测回合，命令在就 ready。验收一眼可核：grok/agy/codex 检测变 online。
- **状态**：**已批准**（2026-09-05；用户：本机 grok、linux-01 agy/codex、其余自主推进）
- **基线**：`origin/main` @ `24f45bc5`
- **发现自**：编制改小队。不 reopen B156.3 / B295。

## 问题陈述

小队准入只认 `online`。检测走 `WakeHome` → `RunTurn` 发 `ping`。`RunTurn` 名单只有 opencode，grok/agy/codex 一律「未实装」→ `unreachable`/`pending`。现网 grok@mac-02 last_error 就是这句。不把他们标上线，换成 grok/agy/codex 之后小队没人可派。

现状读数：`internal/hostapi/driver.go` `supportedCLIs` 仅 opencode；`probe.go` `runWake` 无条件 `detectTurn`；`lookPathWithFallback` 对名单外 CLI 不试常见安装位。图 `codegraph sym WakeHome` 摘要仍写「不是 RunTurn」——**图覆盖债**，以源码为准。

## 方案

名单外 CLI：只查命令在不在（PATH + 常见安装位，含 `~/.grok/bin`、`~/.local/bin`、`/usr/local/bin`）。找到 → `ready`；找不到 → `unreachable`，detail 说找不到命令。不调用 `RunTurn`。opencode 仍走原检测回合。`RunTurn` 对 grok/agy/codex 继续报未实装。

弃选：把 grok/agy/codex 加进 `supportedCLIs`（那是完整对话协议，B156.3 岔口，本期不做）。弃选：检测失败仍手工改库翻成 online。

## 用户故事

1. 作为编制：本机已装 grok，点检测得到 online，能进协调者小队。
2. 作为对照：机器上没有该命令 → unreachable，不会假 online。
3. 作为对照：`RunTurn("grok")` 仍报未实装。

## 测试决定

缝：`Host.WakeHome` ← detect handler / `runWake`。

1. PATH 与安装位都没有 grok：`unreachable`，detail 含「找不到」，**不含**「未实装」；`detectTurn` 不被调用。
2. PATH 里有 grok 可执行文件：`ready`；`detectTurn` 不被调用。
3. PATH 没有，但 `~/.grok/bin/grok` 在：`ready`。
4. 既有 `TestRunTurnUnsupportedCLINamesTheCLI` 仍绿。
5. opencode 仍走回合（既有 `TestWakeHomeReadyRequiresTurnOutputNotCredFile`）。

## L1 plan

1. `runWake`：名单外先 `lookPathWithFallback`；命中 ready 并打成功日志；未命中 unreachable。
2. `lookPathWithFallback`：名单外也试安装位，只找同名二进制，不兜底到 opencode。
3. 改写 `TestWakeHomeUnsupportedCLIWritesUnreachableNotReady`；补 PATH 命中与 fallback 命中。

验收：上述测试绿；变异「名单外仍走 detectTurn」则 2 红。本节点该干什么一律以注入的纪律块为准。
