# B233.10：一次派发生命周期：冻结身份、单次准入、任务终态一次释放

状态：已拍板的单卡实现计划（L3 轻档，跨接缝，不再拆子卡）。

本计划的实现起点是当前工作分支 `cards/B233.10-charter-5`，不是旧的
`linux-01` 本地提交 `94246fc8`。本卡不新增 HTTP、CLI、kind、TaskState、
reservation DTO 或事件类型；保留 `handoff dispatch`、`card dispatch --step`、
`POST /api/tasks` 及 `sched_running`。

## 1. 目标、冻结行为与接缝

一次派发只有一条身份生命周期：卡节点只读选择一个载体并把身份快照带到请求；
执行机按这个载体做一次冻结准入；任务创建成功后，执行占用由任务持有到终态；
成功的 `Done`/`Stop` 各释放一次，重复 `Done`、卡 goroutine、workflow mirror
和 Continue/Resume 都不能再次释放或准入。

| 接缝 | 入口 | 本卡必须锁住的行为 |
|---|---|---|
| S1 编制准入 | `func (s *Service) Select(req IgnitionRequest) (Binding, error)`；`func (s *Service) AdmitFrozen(binding Binding) (Binding, error)` | `Select` 只读、不占容量；`AdmitFrozen` 只认 `binding.Carrier`，按冻结载体做两级 CAS，不重选。 |
| S2 卡节点起源 | `func (s *Server) startCardStep(cardID string, req proto.CardStepReq) error` | 卡节点用 S1 的冻结结果；卡槽位 defer 仍保留，执行占用不在卡 goroutine defer 中释放。 |
| S3 真实 HTTP 派发 | `func (c *Client) Dispatch(ctx context.Context, opts DispatchOpts) (*proto.Task, error)` → `POST /api/tasks` → `func (s *Server) handleDispatch(w http.ResponseWriter, r *http.Request)` | 请求带 `carrier`/`squad`，服务端用冻结身份准入；`Receiver` 只审计，不重新解析/选择。 |
| S4 任务终态 | `func (s *Server) handleDone(w http.ResponseWriter, r *http.Request)`；`func (s *Server) handleStop(w http.ResponseWriter, r *http.Request)` | 终态转换成功才释放；已完成的重复 Done 只回幂等成功，版本号和计数均不再改变。 |
| S5 续作 | `func (m *Manager) Continue(ctx context.Context, taskID, instructions string) error`；`func (m *Manager) ResumeTask(taskID string) bool` | 续作只使用已有 Task 身份，不调用 Select/Admit/AdmitFrozen。 |
| S6 启动对账 | 生产入口 `func (s *Server) RecoverOnStartup(probe func(string) bool, sweep func(string), log *slog.Logger) error`，兼容保留 `func RecoverOnStartup(st *store.Store, hub *Hub, probe func(taskID string) bool, sweep func(taskID string), log *slog.Logger) error` | 在旧任务恢复前，按任务全量快照与 `sched_running` 对账；pending 也算 owner；无主 key 清零；不生成无主 `sched_running`。 |

   ```go
   func (s *Service) AdmitFrozen(binding Binding) (Binding, error) {
       statusLog().Info("冻结载体准入开始", "squad", binding.Squad, "carrier", binding.Carrier,
           "target", binding.Target, "executor", binding.Executor, "model", binding.Model,
           "home_dir", binding.HomeDir)
       if binding.Carrier == "" {
           err := fmt.Errorf("%w: 冻结载体不能为空", ErrInvalid)
           statusLog().Error("冻结载体准入拒绝", "error_kind", "carrier_missing", "cause", err)
           return Binding{}, err
       }
       carrier, err := s.Carrier(binding.Carrier)
       if err != nil {
           statusLog().Error("冻结载体读取失败", "carrier", binding.Carrier, "error_kind", "carrier_read", "cause", err)
           return Binding{}, err
       }
       if carrier.Status != StatusOnline {
           err := fmt.Errorf("%w: 载体 %s 当前状态为 %s", ErrNoHealthy, binding.Carrier, carrier.Status)
           statusLog().Warn("冻结载体不在线", "carrier", binding.Carrier, "error_kind", "carrier_offline", "cause", err)
           return Binding{}, err
       }
       q := Squad{}
       member := SquadMember{Carrier: binding.Carrier}
       if binding.Squad != "" {
           q, err = s.Squad(binding.Squad)
           if err != nil {
               statusLog().Error("冻结小队读取失败", "squad", binding.Squad, "carrier", binding.Carrier, "error_kind", "squad_read", "cause", err)
               return Binding{}, err
           }
           found := false
           for _, candidate := range q.Members {
               if candidate.Carrier == binding.Carrier {
                   member = candidate
                   found = true
                   break
               }
           }
           if !found {
               err := fmt.Errorf("%w: 载体 %s 不在小队 %s", ErrRoleMismatch, binding.Carrier, binding.Squad)
               statusLog().Warn("冻结载体不是小队成员", "squad", binding.Squad, "carrier", binding.Carrier, "error_kind", "member_mismatch", "cause", err)
               return Binding{}, err
           }
       }
       identity := IdentityOf(carrier)
       if binding.Target != identity.Machine || binding.Executor != identity.CLI || binding.HomeDir != identity.HomeDir {
           err := fmt.Errorf("%w: 冻结物理身份与载体登记不一致", ErrRoleMismatch)
           statusLog().Warn("冻结物理身份不匹配", "squad", binding.Squad, "carrier", binding.Carrier,
               "target", binding.Target, "registered_target", identity.Machine,
               "executor", binding.Executor, "registered_executor", identity.CLI,
               "home_dir", binding.HomeDir, "registered_home_dir", identity.HomeDir,
               "error_kind", "physical_mismatch", "cause", err)
           return Binding{}, err
       }
       request := IgnitionRequest{Squad: binding.Squad, Model: binding.Model, Actor: "admit_frozen"}
       admitted, err := s.acquire(q, member, carrier, request)
       if errors.Is(err, errMemberFull) {
           err = ErrNoSlot
       }
       if err != nil {
           statusLog().Error("冻结载体准入失败", "squad", binding.Squad, "carrier", binding.Carrier,
               "member_key", OccupancyMemberKey(binding.Squad, binding.Carrier),
               "carrier_key", OccupancyCarrierKey(binding.Carrier), "error_kind", admissionErrorKind(err), "cause", err)
           return Binding{}, err
       }
       statusLog().Info("冻结载体准入成功", "squad", admitted.Squad, "carrier", admitted.Carrier,
           "target", admitted.Target, "executor", admitted.Executor, "model", admitted.Model,
           "home_dir", admitted.HomeDir)
       return admitted, nil
   }
   ```

```go
const schedRunningKind = "sched_running"

type schedRunningBody struct {
	Count int `json:"count"`
}

func reconcileSchedRunning(st *store.Store, repo schedclient.Registry, log *slog.Logger) error {
	tasks, err := st.ListTasks()
	if err != nil {
		return fmt.Errorf("启动对账读取任务列表: %w", err)
	}
	owned := make(map[string]struct{})
	for _, task := range tasks {
		if task.State.IsTerminal() || task.Carrier == "" {
			continue
		}
		owned[scheduling.OccupancyCarrierKey(task.Carrier)] = struct{}{}
		if task.Squad != "" {
			owned[scheduling.OccupancyMemberKey(task.Squad, task.Carrier)] = struct{}{}
		}
	}
	rows, err := repo.List(schedRunningKind)
	if err != nil {
		return fmt.Errorf("启动对账读取 sched_running: %w", err)
	}
	for _, row := range rows {
		var body schedRunningBody
		if err := json.Unmarshal(row.Body, &body); err != nil {
			log.Error("启动对账解码运行计数失败", "key", row.ID, "version", row.Version, "cause", err)
			return fmt.Errorf("启动对账解码 %s: %w", row.ID, err)
		}
		if body.Count <= 0 {
			continue
		}
		if _, ok := owned[row.ID]; ok {
			log.Info("启动对账保留任务所有的运行计数", "key", row.ID, "count", body.Count, "version", row.Version)
			continue
		}
		payload, err := json.Marshal(schedRunningBody{Count: 0})
		if err != nil {
			return fmt.Errorf("启动对账编码 %s: %w", row.ID, err)
		}
		if _, err := repo.Put(schedRunningKind, row.ID, row.Version, payload, "agentd-startup-reconcile"); err != nil {
			log.Error("启动对账清理无主运行计数失败", "key", row.ID, "count", body.Count, "version", row.Version, "cause", err)
			return fmt.Errorf("启动对账清理 %s: %w", row.ID, err)
		}
		log.Warn("启动对账清理无主运行计数", "key", row.ID, "previous_count", body.Count, "previous_version", row.Version)
	}
	return nil
}
```

实现前必须在当前基线核对 `schedclient` import、`scheduling.Occupancy*Key` 和
`facadeAsRegistry` 已存在；它们的出处是 `internal/schedclient/schedclient.go`、
`internal/scheduling/occupancy.go`、`internal/agentd/server.go`。若实现发现版本
签名不同，保留原始编译错误并停止，不自行改契约。

对账规则是：任何非终态 Task（包括 pending）且 Carrier 非空拥有 carrier key；
Squad 非空再拥有对应 member key；终态任务不拥有任何 key；carrier/member 两类
key 分开处理。匹配记录不把 count 改成任务数，避免启动对账在并发恢复期间制造
第二个写者；只清理正 count 的无主记录。`CreateTask` 在 AdmitFrozen 之后，若
崩溃窗口留下无任务 key，下次启动由该算法回收。

- 编制型：`Select` 读操作、`AdmitFrozen` CAS、carrier 物理身份、squad member
  政策位、direct carrier-only、full/no-healthy/error rollback。
- 编排型：card slot 与 execution occupancy 分离、queue envelope 无预选 carrier、
  卡起源不释放任务 owner。
- 网关型：真实 HTTP `POST /api/tasks`、Receiver 仅审计、Carrier/Squad 必须进入
  Task、启动失败回滚、Done/Stop 幂等边界。
- 传输型：Dispatcher→ledgerstep→client→JSON→server 的字段和 HomeDir 三态。
- 任务型：pending/running/waiting_answer/waiting_review 保持 owner，completed/
  failed 不保持 owner；Continue/Resume 不准入。
- 启动型：全量 `ListTasks`、pending owner、独立 carrier/member 对账、无主
  `sched_running` 清零、CAS 错误 fail closed。
