## 4. 设计裁定与岔口（分歧点显式裁决；协调者审查重点）

**裁定 1｜唤醒分流只对会话房间。** 契约条 47 字面（「wakeconsumer 对**会话房间**消息按 target 分流」）+ 条 30（广播形状删除）。非会话房间的 room_message（旧卡房间 / project: / global——S1 起只读，生产仅剩 pointer 豁免）一律不唤醒、标 seen、游标照推。被否方案：对所有房间统一做寻址 + 全表席位反查——超出条 47 冻结判据，且会让历史卡房间消息在游标重置时误醒（违背旧房间归档）。

**裁定 2｜席位→卡归映射 = 「会话内卡的当前 driver_session 逐字等于 target」。** 条 47/48 同判据（`AddressesCard` 的判据）。不建外部身份注册表（条 48 禁令）；不解析席位语法（无需 `ParseSeatIdentity`——不匹配当前席位的 target 一律走外部分支，行为等价且少一个解析面）。实现上一次 `MessageWakeTargets` 调用取 target 集 + 每会话卡一次 `GetCard` 取当前席位比对；**不逐卡调 `AddressesCard`**（其内部 `replyAuthorOf` 每次全流读，逐卡调用是 N×全流读——判据等价、成本不可接受；源码守卫钉「必经 MessageWakeTargets」）。

**岔口#1（待拍板，默认按契约）｜reply_to 指向换绑前旧席位的行为。**
- breakdown §3.4 ③：「指向已换绑前的旧席位 → 唤醒**当前**席位」；
- 契约 §4.6 条 47 冻结判据：「席位身份命中（target = 会话内某卡**当前** driver_session）」；Ticket 0 冻结的 `WakeTargets` 注释同样只认「作者若是某卡**当前**席位」。
- 两者字面冲突：旧席位回复的 target 是旧席位串 ≠ 任何当前席位 → 按契约**不命中**→ 外部/未匹配分支（零 keystone Wake、日志、未读承载）。
- **本计划默认按契约实现**（旧席位不唤醒），对应测试 `TestB3583ReplyToReboundSeat…` 的断言就是冲突点本体，翻转成本一处。若协调者拍板按 breakdown（旧席位回复唤醒该卡当前席位）：翻转方案 = 在 `roomMessageWakeEvents` 的席位比对未命中后追加席位历史归映射（扫会话内各卡的 `EvDriverTakeover{from,to}`/`EvDriverSeatBound{to}` 载荷，target 出现在 from/to → 归属该卡 → 唤醒其当前席位，~30 行，keystone 本就按卡当前席位 Resume，天然满足「旧席位身份不再命中」）——契约条 47 需同步增补冻结条目，**不得只在实现里私自翻转**。

**裁定 3｜WakeMessage 载荷 = `Summary: truncateRunes(msg.Body, 400)`（既有 helper）。** keystone 类型不动（硬约束）；引用条/未读数由被唤醒方首拉——契约已冻结此读法（外部通道的三件套在 `SessionWake`，见裁定 6），**不另起**。命中条 = 命中消息正文（breakdown ③「Summary 含命中条正文」）。

**裁定 4｜外部分支不加身份分类。** target 未命中会话内卡当前席位 → 统一记「外部/未匹配命中」：`s.log.Info` 一行（session、seq、targets），零 keystone Wake、事件标 seen、游标照推（条 47）。`@非成员`、`@不存在的卡`、`@外部身份`、旧席位回复四个形状都落此分支——覆盖 breakdown ③ 的全部零 Wake 反例。

**裁定 5｜referenced 查找用 `svc.History(msg.Room, 0, 0)` 默认窗（historyDefaultLimit=200，取该房间**最后** 200 条）。** 被引用消息在窗外时省键（与「ReplyTo 无效省键」同出口降级）。被否方案：`limit=math.MaxInt` 触发 `make(…, 0, limit)` 巨量预分配。窗上限记为已知边界，不阻塞。

**裁定 6｜三件套装配归通道（CLI stdout），席位半边载荷最小化。** `SessionWake{Session, Hit, Referenced, Unread}` 只在 `session wait` 输出；keystone `WakeMessage` 只带 Summary（裁定 3）。两半边载荷形状不同是契约冻结的设计（§3.8 vs §8.1 首拉读法），不是不对称缺陷。

**裁定 7｜CLI 游标介质挂载点 = `openRoomService`。** 条 44 要求 unread 与 `ListSessions(member)` 同一投影（同一游标介质）。`collab.New` 默认纯内存空游标；在 `openRoomService`（cmd/room.go 组装点内）挂 `cursor.New(DataDir/room-cursors.json)` 是唯一同时满足「不新增组装点」（契约 §3.8）与「组装点内绑定」纪律的落点。对既有 room 命令行为中性（§0 交代表已核对）。

**裁定 8｜`s.rooms == nil` 防御 = Error 日志 + 不唤醒。** 宁缺毋滥（`AddressesCard` 注释同款纪律）；`SetupAutomation` 保证非 nil，此分支只在误组装时可达，必须可查不得静默。

// 返回 human=false 的合法情形：by_system/pointer 系统结构行（恒不唤醒，契约

func decodeRoomMessageForWake(ev proto.LedgerEvent) (proto.RoomMessage, bool, error) {
	var msg proto.RoomMessage
	if err := json.Unmarshal(ev.Payload, &msg); err != nil {
		return proto.RoomMessage{}, false,
			fmt.Errorf("事件 %d 的 room_message 解码失败: %w", ev.Seq, err)
	}

	if err := json.Unmarshal(ev.Payload, &fields); err != nil {
		return proto.RoomMessage{}, false,
			fmt.Errorf("事件 %d 的 room_message 字段解码失败: %w", ev.Seq, err)

		bytes.Equal(bytes.TrimSpace(raw), []byte("null")) {
		return msg, false, nil
	}

// roomMessageWakeEvents 是会话消息的寻址分流（契约 §3.8、条 47/48/50）。
// 只对会话房间（room.IsSessionRoom）的人类形状消息做寻址判定；判定唯一入口
// collab.Service.MessageWakeTargets（agentd 不解析 mentions，不建外部身份
// 注册表）。分流：
//   - target = 会话内某卡当前 driver_session → WakeMessage{Card:该卡} 恰一次
//     （同卡多命中去重）；
//   - 其余 target（外部身份/非成员/旧席位/不存在的卡）→ 零 keystone Wake，
//     Info 日志可查，未读由事件+游标天然承载（推醒走 session wait 订阅通道）。
// 非会话房间的消息一律不唤醒：旧房间只读归档（S1），广播形状已删（条 30）。
// 寻址判定读账本失败上抛；会话本体读失败宁缺毋滥（Error 日志 + 不唤醒，
// 同 AddressesCard 的装配缺失纪律）。
func (s *Server) roomMessageWakeEvents(ev proto.LedgerEvent) ([]keystone.WakeEvent, error) {
	msg, human, err := decodeRoomMessageForWake(ev)
	if err != nil || !human {
		return nil, err
	}
	if s.rooms == nil {
		s.log.Error("会话消息寻址判定不可用：collab 服务未装配，消息不唤醒",
			"seq", ev.Seq, "room", msg.Room)
		return nil, nil
	}
	if !room.IsSessionRoom(msg.Room) {
		s.log.Debug("非会话房间消息不唤醒（旧房间只读归档，广播形状已删）",
			"seq", ev.Seq, "room", msg.Room)
		return nil, nil
	}
	targets, err := s.rooms.MessageWakeTargets(msg)
	if err != nil {
		return nil, fmt.Errorf("事件 %d 的会话寻址判定失败: %w", ev.Seq, err)
	}
	if len(targets) == 0 {
		s.log.Debug("会话消息无寻址，不唤醒", "seq", ev.Seq, "session", msg.Room)
		return nil, nil
	}
	session, err := s.autoLedger.GetSession(msg.Room)
	if err != nil {
		s.log.Error("会话消息所在会话读取失败，不唤醒",
			"seq", ev.Seq, "session", msg.Room, "cause", err)
		return nil, nil
	}
	bySeat := make(map[string]string, len(session.Cards))
	for _, cardID := range session.Cards {
		card, err := s.autoLedger.GetCard(cardID)
		if err != nil {
			s.log.Error("会话卡席位读取失败，该卡不参与本次唤醒",
				"seq", ev.Seq, "session", msg.Room, "card", cardID, "cause", err)
			continue
		}
		if card.DriverSession != "" {
			bySeat[card.DriverSession] = cardID
		}
	}
	var wakes []keystone.WakeEvent
	seenCard := make(map[string]bool, len(targets))
	external := make([]string, 0, len(targets))
	for _, target := range targets {
		cardID, ok := bySeat[target]
		if !ok {
			external = append(external, target)
			continue
		}
		if seenCard[cardID] {
			continue
		}
		seenCard[cardID] = true
		wakes = append(wakes, keystone.WakeEvent{
			Kind: keystone.WakeMessage, Card: cardID,
			Summary: truncateRunes(msg.Body, 400),
		})
	}
	if len(external) > 0 {
		s.log.Info("会话消息外部身份命中：不经 keystone，推醒走 session wait 订阅通道",
			"seq", ev.Seq, "session", msg.Room, "targets", external)
	}
	return wakes, nil
}

// runSessionWait 是 R1 通道本体（契约条 39–46）。member 与寻址 target 逐字
// 相等（不透明串，不做大小写/前后缀归一）；--since 缺省 = 启动时流尾（排他），
// 只等新事件；只对会话房间的 EvRoomMessage 做命中判定，其余事件推进游标、
// 零输出；不落账、不推进未读游标、不经 keystone（订阅只读，条 45）。
func runSessionWait(cmd *cobra.Command, member string, sinceFlag int64, sinceSet bool, timeout time.Duration) error {
	slog.SetDefault(logx.Setup("cli", ""))
	slog.Info("session wait 入口", "member", member, "since", sinceFlag,
		"since_set", sinceSet, "timeout", timeout.String())
	svc, st, err := openRoomService()
	if err != nil {
		slog.Error("session wait 打开会话服务失败", "member", member, "cause", err)
		return fmt.Errorf("session wait 打开会话服务: %w", err)
	}
	defer st.Close()
	cursor := sinceFlag
	if !sinceSet {
		cursor, err = st.MaxSeq()
		if err != nil {
			return fmt.Errorf("session wait 读取起点: %w", err)
		}
	}
	ctx := cmd.Context()
	if timeout > 0 {
		var cancel context.CancelFunc
		ctx, cancel = context.WithTimeout(ctx, timeout)
		defer cancel()
	}
	enc := json.NewEncoder(cmd.OutOrStdout())
	ticker := time.NewTicker(sessionWaitPollInterval)
	defer ticker.Stop()
	for {
		events, err := st.EventsFromAsc(nil, cursor, 500)
		if err != nil {
			return fmt.Errorf("session wait 读取事件流: %w", err)
		}
		for _, ev := range events {
			cursor = ev.Seq // 其余事件类型推进游标、零输出（条 41）
			if ev.Type != ledger.EvRoomMessage {
				continue
			}
			var msg proto.RoomMessage
			if err := json.Unmarshal(ev.Payload, &msg); err != nil {
				return fmt.Errorf("session wait 事件 %d 载荷解码失败: %w", ev.Seq, err)
			}
			if !room.IsSessionRoom(msg.Room) {
				continue
			}
			targets, err := svc.MessageWakeTargets(msg)
			if err != nil {
				return fmt.Errorf("session wait 事件 %d 寻址判定失败: %w", ev.Seq, err)
			}
			hit := false
			for _, target := range targets {
				if target == member { // 逐字相等（条 39）
					hit = true
					break
				}
			}
			if !hit {
				continue
			}
			wake, err := buildSessionWake(svc, ev, msg, member)
			if err != nil {
				return err
			}
			if err := enc.Encode(wake); err != nil {
				return fmt.Errorf("session wait 输出唤醒载荷: %w", err)
			}
			slog.Info("session wait 命中并输出", "member", member,
				"session", msg.Room, "seq", ev.Seq)
			return nil // 一次性原语：首个命中输出后退出 0（条 46）
		}
		select {
		case <-ctx.Done():
			slog.Info("session wait 超时退出", "member", member, "timeout", timeout.String())
			return &exitCodeError{code: ExitTimeout, err: fmt.Errorf("session wait 超时")}
		case <-ticker.C:
		}
	}
}

// buildSessionWake 装配三件套（spec §4.3：命中条 + 引用条 + 未读数）。
// referenced 取 ReplyTo 指向消息的引用条；History 默认窗（200 条）外或解码
// 失败按「无引用锚」省键（plan 裁定 5 的降级声明）。unread 与
// ListSessions(member) 的 Unread 同一投影（条 44——同一游标介质，含命中条）。
func buildSessionWake(svc *collab.Service, ev proto.LedgerEvent, msg proto.RoomMessage, member string) (proto.SessionWake, error) {
	wake := proto.SessionWake{
		Session: msg.Room,
		Hit: proto.SessionCite{
			Seq: ev.Seq, Room: msg.Room, Actor: ev.Actor, Body: msg.Body,
		},
	}
	if msg.ReplyTo > 0 {
		history, err := svc.History(msg.Room, 0, 0)
		if err != nil {
			return proto.SessionWake{}, fmt.Errorf("session wait 读取引用条: %w", err)
		}
		for _, h := range history {
			if h.Seq != msg.ReplyTo {
				continue
			}
			var ref proto.RoomMessage
			if json.Unmarshal(h.Payload, &ref) == nil {
				wake.Referenced = &proto.SessionCite{
					Seq: h.Seq, Room: msg.Room, Actor: h.Actor, Body: ref.Body,
				}
			}
			break
		}
	}
	summaries, err := svc.ListSessions(member)
	if err != nil {
		return proto.SessionWake{}, fmt.Errorf("session wait 读未读投影: %w", err)
	}
	for _, summary := range summaries {
		if summary.ID == msg.Room {
			wake.Unread = summary.Unread
			break
		}
	}
	return wake, nil
}

2. **静默失败/误导报错**：解码失败消费侧上抛（既有形状，`TestB353Automation…wantErr` 保留）、CLI 侧报错不静默跳过（`runSessionWait` 解码/寻址失败 return err）；`GetSession`/`GetCard` 读失败 Error 日志 + 不唤醒（宁缺毋滥，可查）；keystone Wake 失败走既有 needs_human 升级（零改动）。
3. **跨平台假设**：无——纯进程内消费循环 + 纯 Go CLI；`TestServePermissionHook…` 的 unix socket 红与本卡无关（§3 清单 19）。
4. **假红/假绿**：全部唤醒断言穿真账本事件流 + fake keystone 观测点；「外部目标不唤醒」反例存在（`TestB3583NonMemberAndMissingCardTargetsDoNotWake`/`MixedHits`）——防有人顺手加广播兜底让测试全绿；三发变异（Task 2 A/B/C）+ Task 3/4 变异锁「可变红」。
5. **门禁绕过**：「结构事件不唤醒」逐值反例锁死（`TestB3583StructureEventsNeverWake`）；agentd/cmd 双源码守卫——mentions 不在消费面解析、唤醒必经 `MessageWakeTargets`、无成员集合形状；不建外部身份注册表（实现里没有身份表，只有 `bySeat` 临时映射，随消息即弃）。
6. **序列化边界**：`RoomMessage.ReplyTo` 从落账 JSON 到消费解码——`reply_to` 缺省（无键=0=无寻址）与正值（隐式寻址）两态有测试（`TestB3583NoAddressingDoesNotWake` vs `ReplyToSeatAuthor`；omitempty 编码侧由 Task 1 之前的 `sessions_fixture_test.go` 既有 roundtrip 锁）；`SessionWake.Referenced` 指针区分「缺键」与「零值」（Task 1 omitempty 断言 + Task 4 输出测试）——两端各有测试之外，CLI stdout→JSON 解码这一链路在 `TestSessionWaitOutputsHitJSON` 穿真实编码边界。
7. **枚举新值过既有白名单**：`session_*` 四值 + `driver_seat_bound`/`driver_takeover` 逐值零唤醒反例（镜像应用：新值必须全部落在「不唤醒」分支）；kind 白名单已废止，唤醒路径不再按 kind 分权（守卫禁 `proto.RoomMsgUser`）。
8. **承重安全属性**：「无寻址不唤醒」（变异 A 红）与「结构事件不唤醒」（逐值反例）各一支可变红测试；「旧席位身份不再命中」由 `TestB3583ReboundCardMentionHitsNewSeat` 的载荷断言锁（keystone 只 Resume 卡的当前席位）。
9. **webview 候选族**：无——不触浏览器面；通道是 CLI stdout（TS 消费归 S6 另行过族）。
