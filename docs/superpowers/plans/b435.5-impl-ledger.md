3. **时间列规范化**：`time.Time`（PG timestamptz）→ `UTC().Format(RFC3339Nano)`；文本（SQLite TEXT）能按 RFC3339Nano 解析的同样转 UTC 再格式化，解析不了**保留原串**；NULL → 空串。两方言同函数 `normalizeRetiredTime`，SQLite 测试覆盖「非 UTC 偏移 → UTC」「旧串原样」，PG 孪生覆盖 timestamptz。——§8「时间列规范化方式（须两方言一致且有测试）」授权内。
4. **并发手段（H2）**：PG 取 `pg_advisory_xact_lock(915601)`（与 `mutate` 同一把锁）；SQLite 以事务首条零行 `UPDATE ledger_meta SET value = value WHERE key = …` 先取写锁，再探测——后到者在 busy_timeout 上排队后看到已删状态。——§8「PG 并发的具体手段」授权内（选 advisory xact lock）；SQLite 侧是同一授权的同构手段。
5. **零新行不写键 + 去重**：被删行与已留痕行全字段相同即去重；去重后零新行则不追加批次、不写键（新库因此键不存在）。Warn 对**每条被删的 seat_desktops 行**各一条（含与已留痕行重复的行——它仍是本次被删的记录），只在提交后打。——Q1 甲 / Q7 甲裁决的落实细节，未越权。
