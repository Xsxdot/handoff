## 偏离与自主决定

- 已打开为 tui 的未归属终态任务留原位（与项目组「已打开 tui 不沉组」一致）；`prefs.hideArchived` 开启时未归属的「已结束」行同样隐藏（与项目组一致）。均为沿用既有口径，非新规则。

## 现象

桌面左栏「未归属」堆着已删除项目的任务，一直在、去不掉。生产只读读数（2026-10-19）：scope=all 1441 条中未归属 269 条，全部终态（completed 228 / failed 41），在 linux-01 227、macbook-pro 42；repo 均为已注销的 benchmarking* / bench-runs / handoff-server-v2 / executor-bench-fixtures。

## 根因

B288 让项目组的终态任务沉进默认收起的「已结束」行，但 `archived.ts` 明确不收未归属（「树末尾的未归属分组在管它们」），而未归属分组把全部任务平铺、没有折叠，也没有隐藏/删除动作。项目注销后其任务的 `project_id` 读时 join 为空，全部落进这里。

## 修法

`ProjectTree` 未归属分组按同一判据拆两段：未终态 / 缓冲窗内 / 已打开 → 原位行；其余 → 默认收起的「已结束 N」行（共用 `openArchived` 开合状态，key `unowned-archive`），点开显示、可打开可拖拽；搜索时自动展开。
