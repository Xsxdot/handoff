## Task 1 — B198：文件夹数量默认可藏

**范围**：`web/src/app/tree/treePrefs.ts`、`treePrefs.test.ts`、`TreePrefsMenu.tsx`、`ProjectTree.tsx`、`ProjectTree.test.tsx`、`web/src/app/settings/GeneralPage.tsx`、`GeneralPage.test.tsx`。
**测试**：`npx vitest run src/app/tree/treePrefs.test.ts src/app/tree/ProjectTree.test.tsx src/app/settings/GeneralPage.test.tsx src/app/tree/RowCounts.test.tsx`
**不跑**：全量 vitest（收尾才跑）、go test。

### 先写失败测试

1. `treePrefs.test.ts`：
   - `DEFAULT_PREFS.hideDirCounts === true`
   - 旧盘 JSON（无 `hideDirCounts`，有 `projectSort: 'name'`、`hiddenProjects: ['p2']`）读回来 `hideDirCounts === true` 且排序/名单仍在
   - `savePrefs({ ...DEFAULT_PREFS, hideDirCounts: false })` 再 `loadPrefs()` 得 `false`
2. `GeneralPage.test.tsx`：默认勾选「隐藏文件夹数量」；点一次后 `localStorage` 里 `hideDirCounts === false`
3. `ProjectTree.test.tsx`：默认 `queryByTitle('开发目录')` 为 null；打开显示偏好、点「隐藏文件夹数量」取消勾选后，项目行看得到开发目录

跑红：字段不存在 / 默认仍显示。

### 最小实现

- `TreePrefs` 加 `hideDirCounts: boolean`；`DEFAULT_PREFS.hideDirCounts = true`
- `isPrefs`：`(p.hideDirCounts === undefined \|\| typeof p.hideDirCounts === 'boolean')`
- 加载补默认：`hideDirCounts: p.hideDirCounts !== false`（缺字段 → 藏）。不 bump `v`。注释写明为什么默认与另外两个 hide 相反：用户已量过这段是噪声。
- `TreePrefsMenu` / `GeneralPage` 在「隐藏已结束分组」下加 check：「隐藏文件夹数量」
- `ProjectTree` 两处：`dirs={prefs.hideDirCounts ? undefined : counts.dirs}`

`RowCounts.tsx` 不改。

### 日志与注释

- 无新服务端路径，不打 logger。
- `treePrefs.ts` 文件头职责补上第五条规则；补默认的函数注释写「为什么缺字段当 true」。
- `ProjectTree` 传 `undefined` 的那一行用中文注释：藏的是「不传 dirs」，不是改 RowCounts。

### 验收

- 上述 vitest 文件全绿
- `npx tsc -b` 0 错

## 缺陷族

| 族 | B198 | B197 | B206 |
|---|---|---|---|
| 生命周期 | 无，因为偏好只活在当前浏览器 localStorage，无进程资源 | 无，因为模板追加版本不回收旧版，v2 仍可读 | 无，因为只改声明 |
