- **S3 驻场者**：任意 agent `handoff session sit <session> --as <身份>`（Q5）登记为该会话房间驻场者；`handoff session wait <session>` 作为驻场者收件——命中 = 显式寻址驻场者 ∪ 默认收件人落到驻场者，判定只经 `collab.Service.Matches`；同会话卡协调者不被唤醒（K0 判定表第 5 行先于第 6 行，C-231 零 Wake）。已有驻场者时第二次 sit 被拒（C-414）。驻场者可回复（Q4）。
- **S4b**：有驻场者时，人类无 @ 发言改到驻场者，其余（@卡、reply_to、`agent:` 无 @、多根卡）不变。
- **S9 驻场者升格**：驻场者在同会话 `card bind` 一张卡后，驻场登记保留；两种地址各自游标、各自收件（`session wait` / `card wait`）；`session detail` 出 `resident` 与 `seat` 两行（N2）；`session stand` 不改卡席位列。
- **驻场者写面**：`session sit/stand`（Q5/Q7/Q8/Q9/Q14），一房间至多一名由库层主键兑现、并发两次 sit 恰一成功；桌面端地址三列（`--desktop-session`）为 O2 门铃信的收件前提（C-406/C-409）。
- **F-RM1**：push 协调者 resume 回合注入 `HANDOFF_SESSION_CLI/ID`（Q2），按简报（Q1）以席位身份回房间；launch 回合按 Q3。
- **欠账**：契约 §12 欠账 3（session wait 半边）、7（写面与命令）、12 的前半（`runSessionWait` 等入图）；契约 §13 第 2、5 条（本稿吸收：第 2 条按 Q5，第 5 条在段 2）。

**本轮做到哪里**：驻场者写面只有 `session sit/stand` 两个 CLI 入口；`--project` 不做。驻场者桌面端地址只写入、不消费（不写信）。

**明确留给后续子卡**：
- **O1**：`session sit --project`、`project room`、系统通知（C-243–245）、投递投影（C-501–517）。O1 复用 R 的 `collab.Service.SitResident`（Q11 甲时）与同一记法校验。
- **O2**：门铃信桥（消费 R 写下的 `cli_session/desktop_session/machine`）、本机判据、组织者简报（含 N1、S8「stand 再 sit」流程，Q8）。
- **X**：B434 退役（含 `cmd/card_seat_desktop.go` 删除——R 不引用其中函数）。
- **W**：TS 镜像 `resident` 成员行。
