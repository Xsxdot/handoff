- 反例假绿：空壳 `ValidateDesktopSessionID` 恒返回错误 → 「拒绝类」用例对空壳天然绿。处置：拒绝用例一律加 `!errors.Is(err, proto.ErrDesktopNotImplemented)`；Store 拒绝用例断言具体哨兵（`ErrBadState`/`ErrCASConflict`/`ErrNotFound`），空壳错误不包它们。

- `ListDesktopLaunchers` 排序：PG 默认 collation 可能非 C（`en_US.UTF-8` 下大小写/标点不按字节序），SQLite 是 BINARY——`ORDER BY project` 两方言结果可能不同。取舍：Go 侧 `slices.SortFunc(strings.Compare)` 按字节序，两方言一致；SQLite 测试用 `Proj-Z/proj-a/proj-b` 钉字节序，PG 测试（门控）钉同一对。
- 时间精度：PG `timestamptz` 微秒精度 → 往返断言的固定时刻纳秒位取 0（`123456000`），否则 PG 腿 `Equal` 假红；取非 UTC 时区逼出时区往返。
