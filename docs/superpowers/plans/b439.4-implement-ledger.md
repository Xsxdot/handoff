## 偏离与自主决定

1. **修复落点选在唯一判据 `Server.IsSelfTarget`，不改六个调用点**（自主决定，落 plan §12
   「局部私有函数/内部命名」权限）：卡面说「以 Server.IsSelfTarget 判本机的调用点不认自名」
   「注入的本机判据认自名」。六个调用点（cmd/agentd.go 任务镜像/预览镜像、scheddrain.go
   carrier.Machine 与 bearing.Machine、desktopwake.go deliverDesktopLetter 与 wakeDesktopSeat、
   pty_api.go）全部经 `s.IsSelfTarget` 求值，故把自名并进该判据即一次覆盖全部调用点，是
   最小且不会漏点的改法。判据取**并集**而非替换：自名判在前，地址判（`config.IsSelfTarget`）
   保留在后，旧别名判（调用点另一侧的 `scheduling.IsLocalMachine`）不动——满足「保留今天的
   旧别名/地址判法不回退」。无自名（`cfg.Name==""`）时新分支恒不触发，S5 逐点不变。
2. **deliverDesktopLetter 用例断言日志而非回执**（自主决定，落 plan §12「测试组织」权限）：
   判错时 `clientForTarget` 经 `ResolveTarget` 已把自名短路成本机 client，转发仍绕回本机、
   回执照常 `written=true`——只凭结果分辨不出分支。改以转发分支独有日志
   「拉起器投递转交到拉起器所在机器」的缺席 + 本机分支日志「拉起器来信已落盘」的存在为判据。
3. **②的五个非派发入口测试复用既有夹具**（自主决定，落 §12「测试组织」权限）：scheddrain 两处
   用 `seedQueueCoordinator`/`bearingTraceRunner`，desktopwake 两处用 `newDesktopSliceEnv`/
   `bindDesktopSeatAt`/`newB434MaterialEnv`，pty 用 `newPoolWiringServer`；不新造生产缝。
4. **图覆盖债**（环境事实，非自主决定）：`codegraph --repo . sym IsSelfTarget` 报
   `读取基线 codegraph/baseline.json: no such file or directory`——该基线已由 B436
   （`2239e603`）整体删除，本仓已无图可查。按纪律以 grep 复核调用面并记此债，未以 grep 冒充查图。
