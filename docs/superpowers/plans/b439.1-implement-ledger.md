## 偏离与自主决定

1. **F3 门控（协调者裁决，非偏离）**：plan F3 原写「`RecordDispatchAndLinkTask` 无条件拒
   `snap.Target==''`」；协调者工单 `2ee567d7` 裁决取**乙**并收紧——拒收门控 = 「本账本是共享
   账本」，由组装点按 DSN 显式声明（`ledger.OpenShared` / `ledger.Open`），不按 SQL 方言推断、
   不按「是否配了 name」判；无 DSN 本机账本照旧接受 `''`（S5）。落在 plan 授权（§12 必须升级项
   「任何让『新落账一律全队名字』弱化的选择」由协调者拍板），已在正文记录。
2. **agentd 准入保留本机别名回退（自主决定，落在 plan 决策权限内）**：plan §6.1 写「B233.27
   准入改自名判」，§6.3 又写「WU1 期间 `local`/`本机`/hostname 输入行为不变（S5/S6 边界），
   只杀 `''` 落账」。二者对「有自名的机器收到 `local` 别名」冲突。实现取 §6.3 口径：
   `IsSelfMachine` 先按自名判、**再回退**地址判与本机别名（`local`/`本机`/hostname 在 WU1 仍
   视作本机）；旧别名的拒收（S6）留给 WU3。理由：若 WU1 就让有自名机器拒收 `machine: local`
   的既有载体，会无文案地打断现网默认载体派发，违反 §6.3。属 §12「内部命名/局部私有函数」权限。
3. **存量 `''` WorkBranch 跳过的判据（自主决定）**：plan §4.2 写「`workInfo.Target==''`（存量）
   → 跳过跨机判据」。但无自名机器的 `''` 是**本机身份**（新写入也是 `''`），一律跳过会破坏 S5
   的跨机拒接。实现加判据：`selfIdentity = ResolveTarget("")` 非空（= 有自名机器）才把 `''` 当
   历史无归属并跳过；无自名机器按字面比对，S5 逐点不变。属 plan §4.2 缝内实现细节。
4. **`reconcile` 对「挂账目标机不在本机机器清单」加 WARN（自主决定）**：plan §6.1 镜像文件集
   未列该 WARN，但 §6.2 反例断言要求「WARN 带 target/task 且健康行不刷新」。原实现对该类挂账
   静默 `continue`，无 WARN。补一条 WARN（带 card/target/task/node/attempt），行为与既有
   「机器或挂账已不在」退订原因不冲突。属 §12「局部私有函数/测试组织」权限。
5. **挂载门补充 `LedgerMounted` 守卫（自主决定）**：§4.5 更正要求「有 DSN 缺 name 时不打开任何
   账本、不回退本机 SQLite」，但 `RecoverOnStartup` 依赖自动化账本门面、未挂载必然失败，会顶死
   agentd（与 S2「照常起」矛盾）。新增 `Server.LedgerMounted()`，未挂载时跳过启动恢复对账并
   WARN。属组装点接线，落在 `cmd/agentd.go` 文件集内。
6. **`initflow` name 字段位置（自主决定）**：置于 `role` 之后、所有角色可见；金样按 `-update`
   重录。属 §12「测试组织/字段表」权限。
