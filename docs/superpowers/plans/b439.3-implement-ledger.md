## 偏离与自主决定

1. **scheduling 门控收敛落在 Service 私有方法，不动包级 `IsLocalMachine`**（自主决定，落 §12
   「内部命名/局部私有函数」权限）：plan §4.1 字面要改 `scheduling.IsLocalMachine`。实现保留包级
   `IsLocalMachine`（物理别名语义），新增 `Service.selfName` + `SetSelfName` + 私有
   `Service.isLocalMachine`，把 S6 门控收敛在编制域登记入口 `checkKnownMachine`。理由：包级函数被
   WU3 文件集之外的 `desktopwake.go`/`scheddrain.go` 与 `samePhysicalMachine` 消费，改其语义会越界
   波及其它入口；`samePhysicalMachine`（B398）必须保留别名语义。
2. **模板 S6 只判 `tpl.Def.Target`，不判 `req.Target`**（自主决定，落 §4.2 缝内实现细节）：plan §4.7
   写「模板 target ∈ 保留字/hostname → 拒发」。`req.Target` 由 CLI / agentd step 各自入口拒收；agentd
   step 的 `req.Target` 在绑定小队/载体时会等于冻结 `Binding.Target`，若在 `ViaTemplate` 统一拒收会误杀
   B398 冻结派发（旧别名载体）。故只判模板缺省 target。
   **已按协调者裁决修正**：冻结派发的旧别名 `Binding.Target` 不再视为「不该误杀」——它在接收端准入
   `AdmitFrozen` 按 S6 拒发（见本文件新增 #10）。模板侧仍只判 `tpl.Def.Target`（请求覆盖由各入口自拒），
   此点不变。
3. **agentd step 的 S6 拒收点在 `startCardStep` 的 `req.Target`，非 `resolveStepDiscipline`**（自主决定）：
   plan §8.1 只点名 `resolveStepDiscipline`/`disciplineTargetCap` 的短路改自名判。实现把拒收放在
   `startCardStep`（`req.Target` 是请求显式目标），短路确改为 `s.IsSelfMachine`（自名判）；避免误杀
   冻结 `Binding.Target`。
   **已按协调者裁决修正**：`startCardStep` 的 `req.Target` 拒收保留；但「避免误杀冻结 `Binding.Target`」
   的理由作废——冻结 `Binding.Target` 为旧别名时改由接收端准入 `AdmitFrozen` 按 S6 拒发（见新增 #10）。
4. **machineupgrade 无自名时保留今天的 hostname 判法**（自主决定，**与 plan §4.7 字面不一致，需知悉**）：
   plan §4.7 写「升级无自名机器走 addr 回退判据」。实现无自名时保留 `isLocalMachineName` 的语义
   （空串/本机/hostname），未改成 addr 判据。理由：S5 是「零新行为的回归锁」，改 addr 判据会让
   「本机」/hostname 从「本机」变成「未在 targets」的 404，改变既有行为并打破既有用例
   `TestMachineUpgradeRefusesLocal`。plan 未授权弱化 S5，故取保守口径。
5. **launcher S6 拒收形态**（自主决定）：plan §8.1 写 `probeLauncherMachine` 有自名时旧别名拒绝。
   `probeLauncherMachine` 是 `status` 探活函数、不写账本，无「登记」动作可拒；实现返回
   `reach="不可探（本机旧别名）"` + warn 点名改成自名。
6. **S7 WARN「每轮每条」未做跨轮去重**（自主决定，落 §4.6）：每轮对每条非终态 '' 挂账打一次 WARN，
   靠对账周期天然限频（同一条不在一轮内刷屏）；未加跨轮记忆。
7. **健康面字段名 `unattributed_inflight`**（自主决定）：plan 只要求「无归属在飞挂账 N 条」，未定键名；
   取加性整数键。
8. **新增 config 判据 `IsLegacyLocalAlias` / `Config.LegacyLocalAliasError`**（自主决定，落 §12
   「内部命名」）：S6 拒收的唯一判据来源（F2 要求 config 是唯一定义点）。
9. **ledger 新增 `NonTerminalLinks` / `UnattributedInflightCount`**（自主决定，落 §12）：plan §8.1 说
   「加一个计数读方法或复用 `LiveMirrorTargets` 的 '' 键」；S7 WARN 需 per-link 粒度，故抽私有
   `lastMirroredType` 并加两个导出读方法（`LiveMirrorTargets` 改为共用）。
10. **派发准入 `AdmitFrozen` 拒存量旧别名，判据经组装点注入 `config.IsLegacyLocalAlias`**（修复轮新增，
    自主决定，落 §12「内部命名/局部私有函数」权限）：协调者裁决 S6 欠交——有自名的机器上，派发路径
    遇到**存量 carrier 记录的 `machine`**（或冻结 `Binding.Target`）为旧别名时，必须拒发，不得经
    `samePhysicalMachine` 的别名语义静默当本机放行，且拒发须在任何占用写入之前。实现：
    `scheduling.Service` 新增 `legacyAlias func(string) bool` 字段 + `SetLegacyAlias` 注入缝，
    `cmd/agentd.go` 组装点注入 `config.IsLegacyLocalAlias`（旧别名词法唯一定义点在 config，本域不另立
    词表）；`AdmitFrozen` 在物理核验与 `acquire` 之前调私有 `rejectLegacyCarrierAlias`，返回包
    `ErrInvalid` 的可行动错误（点名 carrier 名、当前 machine 值、改成自名）。`samePhysicalMachine` 语义
    不动（仍供 desktopwake/scheddrain 等非派发入口消费）；无自名或未注入判据时返回 nil（S5 逐点不变）。
