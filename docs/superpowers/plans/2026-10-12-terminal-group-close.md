# 顶部标签关闭与终端生命周期一致性修复

当前修订：R2（2026-10-12 用户点验反馈：整组关闭只能确认一次）。以下初稿和 R1 记录保留作已部署版本的历史依据；R2 行为以文末交接为准。

基线：`b6c4d684`，干净 detached worktree。用户授权修复，指定实现由 `gpt-6-luna` 子 agent 执行；本地协调者审查与验证。Bug 已定位，无新增外部契约或后台回收策略。

## 目标和边界

顶部 TabBar 的 × 关闭整组，应使组内终端走 Shell 现有的确认/DELETE/成功后移除路径，并保护未保存文件。窗格 ×、左栏 ×、浮窗关闭的现有结果保持一致。布局纯函数不承担资源释放；TerminalTab 的普通卸载继续只断连接，以保留切页/断线恢复行为。

生产入口：TabBar.tsx 的 onCloseGroup → WorkbenchPage.tsx 当前直接传 api.closeGroup → useWorkbench.ts 的纯布局关闭 → TerminalTab.tsx 卸载只断连接。这条入口绕过 Shell.tsx 的 beforeCloseTab/confirmClosePty。现有 DELETE 已将 machine 从 tab 本身带到后端。

文件范围：web/src/app/workbench/WorkbenchPage.tsx、web/src/app/shell/Shell.tsx，必要的同目录行为测试；尽量复用既有关闭流程，不新增后台状态、TTL、接口、依赖或通用资源管理器。不处理已遗留后台终端，不改本设备布局迁移、移动端资源列表。文档与台账由协调者维护。

## 验收责任

- 顶部 ×（单终端）：先确认；取消时布局和会话仍在；确认时 DELETE 正确 sessionId/machine，成功后移除。
- 多窗格/多终端组：全部终端获得显式结束机会，没有移除整组却留下未处理会话的路径；取消停止后续关闭；失败保留尚未处理项与可行动错误。已确认结束的项无需回滚。
- 混合文件/终端组：脏文件不可被组关闭静默丢弃；确认及取消接入既有文件守卫。干净文件、空组仍能正常关闭。
- 远程终端：结束请求针对 tab 的机器，不受当前选择/聚焦变化影响。
- 正在等待 DELETE 时不能被重复点击或其他关闭请求替换目标；组变化时不删除新增、未被此次请求涵盖的资源。
- 切换 tab、普通页面卸载不 DELETE，保持跨页面可接回的资源语义。
- API 层用现有关闭会话契约；无新增序列化字段或跨平台进程实现。本轮真机需后续部署点验，不能用 mock 代替设备运行证据。

## R2：组级一次确认（取代逐项确认队列）

用户反馈：点顶部 tab × 就是要关闭该 tab 下全部窗口，每个终端弹一次不符合整组关闭意图。协调者确认原实现把资源安全确认错误地投影成多次用户操作；本次维持显式结束的已有权威与 API，将确认合并为一次组级操作，无新增外部契约。

1. 真实 Shell 顶部 ×：一个组含多个终端/混合脏文件时只弹一个组级确认，说明终端数量以及未保存文件的后果；一次确认后处理该次快照所有资源，不再弹逐终端/逐文件确认。
2. 取消：任何布局或会话都未被改动；没有终端会话/脏文件的纯干净文件组或空组可直接关闭。
3. 批量关闭沿既有 machine-aware DELETE；所有本次确认的终端均尝试结束。成功项才移除；失败项留在界面，统一反馈失败并可重试剩余项，不让一次失败把整组从视野抹掉，也不因首项失败就留下其余未尝试项。已成功释放无法回滚。
4. 点击确认前核对本次快照身份及脏文件内容；请求途中新增、替换、移动或修改的内容不得被无条件整组移除。取消/重复触发/in-flight 互斥沿 R1 保持，不能把旧异步结果写进新请求。
5. 原窗格/左栏单项关闭仍用现有单项确认；普通切组、卸载只断连接。移除被替代的逐项推进 ref/nextIndex/waitingTabId 逻辑及旧测试，不并存两套组关闭模式。

文件所有权继续交 gpt-6-luna：Shell.tsx、Shell.test.tsx、必要的 WorkbenchPage.tsx/对应测试；协调者维护文档/图/台账与部署。先从一次确认关闭两个终端的真实入口写有效失败断言，再实现和局部测试；编译/全量 Web 测试/独立审查/变异由协调者收口，随后沿本机已授权部署链重新构建、重启并刷新窗口。保留3个用户已连接会话，设备点验使用另建的临时测试终端，不确认结束用户既有终端。

关键验收：单/多终端一次确认全部 DELETE；混合脏文件一次统一确认；取消零副作用；混合成功失败只保留失败并重试；不同 machine 参数；新增或修改内容保留且告知；重复确认/Escape/另一组×不能覆盖请求；原单项关闭与干净/空组回归。日志记录组级入口、确认、每个外部调用与最终成功/失败集合，注释说明为何聚合确认及失败保留，不新增通用资源管理器。
