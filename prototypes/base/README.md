真实前端（`web/`）的形态镜像基准站。页面清单、导航结构、布局骨架与真实控制台对齐，
内容为代表性占位。fork 副本做交互细化时以本目录为起点。

`index.html` 在 fork 之后被左栏偏好的改动更新过，整份拷贝会把基准打回旧版，所以只搬了

原确认内容：
① 控制台右下角提示框接管原来挂在菜单栏图标上的三条动态提示（有新版 / 有更新待应用 /
上次同步失败）。只有「有新版」有真动作（下载 + 校验 + 打开安装包），主按钮就地转进度条、
完成后文案变「已在访达中打开」；另两条没有可点的补救，主按钮就是「知道了」。与 home 悬浮窗

（提示框消失后的常驻落点，**不给「立即应用」按钮**——重开一次桌面端即等效）/ 执行机版本与
一键升级，本机那行标「随桌面应用一起更新」且不给按钮；③ 托盘只剩「打开控制台」与
「退出（agentd 继续运行）」，图标换成标志。设计见 spec
`docs/superpowers/specs/2026-08-19-desktop-update-surface-design.md`。真实页面开发后对照
该副本验收，通过后推进为已确认。副本还顺带把设置页外壳从旧的 `.footer` 换成 index.html
现用的 `.dock`——那是基准漂移的修复，回流时一并带回。

代码图页的形态基准经 fork 副本 `codegraph/`（`pages/codegraph.html`，读真实扫描数据
`data/graph.json`）走查确认（2026-08-19 初确认，**2026-08-21 定稿**），最终收敛为
**领域图单一主线，三级下钻**：① 领域全景——领域卡（职责一句话 + 类/方法/接口/入口统计
+ 差异徽标，力导向自由分布可拖）+ 领域间连线（线宽=调用处数，点线右栏逐对列
「谁调用了谁的接口」，点卡右栏看职责/内部逻辑/对外开放接口）；② 领域可嵌套——有子领域
再出一层全景，域外领域缩成虚线占位卡（保留调入/调出边，点击横跳）；③ 叶子领域用
「树+图」视图——左树根 = 本域入口 + 对外接口，中间竖向焦点子图（单击换焦点、⌘ 并集、
层级默认上下 2 级、拖动平移 + ⌃滚轮缩放、◀▶ 焦点历史），链上域外节点显示为虚线卡/↗ 行、
点击横跳并聚焦；面包屑逐级返回。领域层级与职责说明由扫描产出 domains 段（原型内置演示，
agentd 拆 api/core 展示嵌套）。走查过程中的全局树+图/地铁图/时序图/调用树/自由节点图
均为试验品，已从原型删除，不进真实功能。真实页面开发后对照该副本验收，通过后推进为已确认。

需求 A（执行耗时统计）与需求 B（自定义启动项）的三处新形态已于 **2026-08-22**
直接回流进 `index.html`（无 fork 副本——两者都是既有页面上的增量，不是新页面形态，
所以走的是「真实页面落地 + 真机验收通过后回灌基准」这条路，没有事前走查环节）：

① **TUI 页头的耗时 chip**（遥测行最右，`task/TimingChip.tsx`）。三分弹出里
「工具（墙钟）」与「工具（时长合计）」**必须同时出现**——并发工具时后者更大，
取其一当另一个用就是在撒谎；`partial` 时另有一段琥珀提示，说明未归类偏大、
不是真实空档。**弹出层按第一个裁剪祖先夹一次**，不靠锚定方向：真机上左锚
向右溢 32px、改右锚后又在 900px（遥测行换行、chip 不再最右）向左溢 34px，
两次 DOM 文本都完整、组件测试都绿——锚定方向是赌注，夹取才是机制。

② **工具行的单次耗时**（`task/ToolCard.tsx`），夹在参数与状态之间。本页刻意
保留多条**不带**耗时的工具行：缺席就一个字都不画，因为 0ms 与「没报出耗时」
在线格式上不可分，画个 0ms 会把「极快」与「没测到」说成同一句话。

③ **空白页与自定义启动项**（`workbench/BlankTab.tsx`，点 tab 条的 ＋ 进入）。
固定三项带快捷键，自定义启动项**刻意不带**——数量不定，印在面板上却按不动的
快捷键会变成一句 UI 说了不算的话；env 文件缺失就地红字标出，不置灰也不拦着点。

回流时顺带修了基准自身一处缺陷：`.tui[hidden]` 没有定向规则，`display:flex`
盖掉 UA 的 `[hidden]{display:none}`，切空白页时两个面板会叠在一起——DOM 上
`hidden` 为 true、页面上照常显示，属性检查看不出来。同文件早先给
`.running-line[hidden]` 打过同款补丁，这次按同一约定补齐。

**刷新时机**：本项目不设常设的同步机制（B131 评估后明确不做）。约定是——
**要 brainstorm 前端形态之前跑一次刷新**，而不是定期刷。理由是漂移的代价按次收，
而这份资产每周只用一两次，维持一套「什么时候刷、由谁刷、怎么判定漂移」的流程
比它要防的问题更贵。
