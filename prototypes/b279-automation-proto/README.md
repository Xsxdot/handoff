# 原型站说明

真实前端（`web/`）的形态镜像基准站。页面清单、导航结构、布局骨架与真实控制台对齐，
内容为代表性占位。fork 副本做交互细化时以本目录为起点。

## 路由

真实前端的路由都挂在 `web/src/app/shell/Shell.tsx` 的 `<Routes>` 下。看板与工单是
工作台内的 `<dialog>` 弹层，不单独成页；中央工作台的三种 tab（终端/文件/TUI）中，
TUI tab 是任务会话主视图。
