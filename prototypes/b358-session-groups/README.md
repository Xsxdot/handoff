## 形态摘要（与 B156.2 房间制的差别）

1. **会话页是一等公民页面，不是工作台 tab**（2026-09-12 用户裁决）：不占 tab 条、不挂面包屑、不带右栏文件树，
   整块中央区归它（与 `pages/board.html` 同构）；入口在左栏底部 dock（`◱`，选中态）。理由：tab 条是「我现在在干的几件事」（可多开、可关、可拖拽分屏），
   而家必须随时可回、位置稳定；`attach` 打开的才是工作台 tab。
2. **锚点翻转**：会话 = 工作单元（人 / 主 agent 开的一场会话），卡是会话里的工作项；
   列表每行带未读与「需要你」标签（不是卡房间列表）。
3. **群聊面**：不分 kind，人 / 主 agent / 各卡协调者各自以自己名义说话；
   群里**只有人话**——结构事件（卡进群、叫机器人、换绑、收口、needs_human）不进聊天流。
4. **会话详情页**（点 ⋯）：成员与成员状态、协调者派发的任务节点、会话 timeline 三块。
   成员状态只报可证实的：能续租的报精确态（工作中 / 监听中），外部会话只报「最后活跃」。
5. **投递寻址化**：`@` 只唤醒被 @ 的；回复 = 隐式 @ 原作者；无寻址的发言谁也不唤醒。
   群聊里四种情形各带一条灰色注解（见下）。
6. **进群 ≠ 配人**：卡条里 `B233.17` 是空座（虚线框）——卡在群里，还没人推。
7. **升级链**：协调者（填补级自己拍）→ @ 主 agent（推翻级）→ @ 人（人工门 / 主 agent 拍不了）。

## 走查要看什么（编号供逐条裁）

- **W1 会话页的占位**（**已定** 2026-09-12）：会话是一等公民页面（不占 tab 条 / 不挂面包屑 / 不带右栏文件树，整块中央区归它）；
  **左栏保留项目树**（全局导航），会话列表是中央区第一栏。未选「会话列表接管左栏」「左栏可折叠」。
- **W2 群聊的干净度**：只有人话、没有进度播报，读起来是「同事在说话」还是「缺上下文」？
- **W3 @ 与引用的呈现**：`@B233.16` 高亮、回复引用条、被 @ 的是「卡号」不是人名——
  这种寻址方式在界面上说不说得清。
- **W4 详情页三块的位置与密度**：成员 / 任务节点 / timeline 是不是把「结构与状态」讲全了，
  有没有该在群聊里、却塞进详情页的东西（或反过来）。
- **W5 卡条**：会话里的卡以横向 chips 呈现；空座卡用虚线 + 琥珀字提示「还没配人」。
- **W6 与看板 / 工作台的关系**：会话为家之后，看板退为「卡视图 / 诊断面」、工作台仍是干活的地方
  （`attach` 从会话跳进工作台 tab）——这个分工认不认？

### 与 v1 的差别（逐条）

1. **左栏 = 「会话 | 任务」两个 tab，点击切换**（v1：左栏恒为项目树，会话列表在中央区第一栏）。
   「会话」tab 放 v1 中央区第一栏的会话列表原样（未读数、「需要你」筛选、预览都在）；
   「任务」tab 放 `index.html` 左栏那棵项目树原样（含 ⌘K 搜索与机器行动作）。会话 tab 上
   聚合全部未读的红徽章（4）——列表收进左栏后，未读信号需要一个 tab 级读数。
2. **会话详情不再整块中央区**（v1：群聊 / 详情占中央区右块，页面为一等公民、无面包屑无右栏）：
   点列表行把会话**开成工作台 tab**——与「工作项」tab 同列，可多开、可关（tab 上 ✕），
   可点「◫ 分屏」与工作项 tab 左右分屏（工作项在左、会话在右）。外壳回到工作台形态：
   面包屑、tab 条、右栏文件树都在（这正是与 v1 W1 裁决相反的取舍）。
3. **群聊面与详情的呈现内容不变**：tab 窗格内部仍是群聊态 ↔ 详情态切换（⋯ 进详情、← 返回），
   投递注解（.anno）一并保留。
4. **「工作项」tab 是 board 形态的最小示意**（四列 + 与会话 mock 同源的卡），只为证明
   「工作项 tab 与会话 tab 同列、可分屏」；完整形态仍以 `pages/board.html` 为准，本页不复刻。

### 走查（对照 W1–W6，在 sessions-v2.html 里验什么）

- **W1 占位（对照项）**：v1 裁的是「一等公民页 + 左栏保留项目树」；本变体给相反答案——
  左栏「会话 | 任务」两 tab 切换、会话进工作台 tab。对比点：家是否还需要「随时可回、位置稳定」？
- **W2 / W3 / W5（应与 v1 逐字同源）**：点「架构物理化」进 tab——群聊干净度、@ 与引用、
  卡条空座的内容 v1 一字未动；若观感变了，是宿主（tab 窗格宽窄）带来的，不是内容改了。
- **W4 详情三块**：tab 内 ⋯ 进详情、← 返回——三块内容不变；验「塞进 tab 后密度是否还站得住」。
- **W6 与看板 / 工作台的关系（对照项）**：tab 条里「工作项」与会话 tab 同列；开第二个会话
  tab（如「桌面端体验」）验**多开**；点 ✕ 验**可关**；点「◫ 分屏」验工作项在左、会话在右。
